# 内容洞察使用说明

登录 NovaFlow 后，从首页左侧进入“内容洞察”。无需配置数据接口或密钥。

## 找内容与关注账号

- **平台热榜**：先选择平台与榜单类型、日期。话题榜用于找选题，热门作品榜用于找具体作品。没有相应能力的平台不会以搜索结果冒充榜单。
- **爆款发现**：搜索作品、搜索账号，或粘贴分享链接/作品 ID。打开详情后可收藏、提取文案、预览下载或导入画布。
- **我的账号 / 竞品监控**：从账号搜索结果添加账号，设置分组和点赞变化提醒阈值。默认每天采集，首次采集建立基线；只有客户端运行且联网时才会采集。
- **选题收藏**：保存备注、项目与创作后发布的作品链接。

首批平台为抖音、小红书、B站、视频号。可用功能由实际平台能力决定，部分接口可能暂时不可用。视频号作品列表按昵称检索，注意同名账号，不能将结果自动视为精确账号归属。

账号对比基于本机已收录样本，不是全量账号统计。缺少的指标显示“暂无数据”。我的账号是用户添加的公开账号分类，不代表平台认证授权，不提供完播率、收入、转化等私有后台指标。

## 导入画布

1. 打开作品，点击“导入画布复刻”。
2. 选择已有项目或新的工作目录，填写改编目标。
3. 选择“仅导入素材”，或“拆解并改编”并选择模型。
4. 下载和媒体检查完成后，进入自动创建的参考画布。视频已连接逐帧拉片节点，来源与改编目标单独保存。

导入需要可用的 FFmpeg。失败或关闭客户端后，可在任务列表继续导入，已完成文件保留。临时下载链接会过期，需要重新解析。图文作品按实际解析得到的图片导入；无法解析时可通过画布素材节点上传本地文件。

拆解改编会调用所选模型，使用相应模型额度；不会自动提交收费图片或视频生成。实际生成沿用既有确认与执行流程。直接复用原片、人物或音乐时，请确认具备相应使用权限。

## 数据与本地存储

监控、收藏、快照和任务记录存放在本机，按 NovaFlow 账号与身份范围隔离。多台设备不共享监控历史；电脑关闭期间不会采集，也不会补造历史数据。恢复后只补采当前数据。

文案提取为异步任务，处理中可查询进度。提交结果未知时不会自动重提。时间戳尚未确认单位时，不直接用于镜头时间对齐。
