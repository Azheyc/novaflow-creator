# 诊断与修订

用于原稿诊断、修改、比较和技能版本试验。遵守本轮权限，只诊断不直接换稿，明确要求修改则交实际替换内容。

## 先确定这次改动的深度

诊断、局部修订和整稿重写不是同一件事。诊断只回答哪里出了什么问题；局部修订保留原稿的结构、声音和意图，只处理已经定位的缺口；整稿重写则先列出必须保留的事实、关系、条件和结尾要求，再重新安排叙述。不要在用户只要求顺句时顺手改动人物动机，也不要在需要重建结构时靠连续换词遮过去。

改动顺序从影响范围最大的地方开始：先看主线关切、人物选择、信息与结局，再看场景承接和段落节奏，最后才看词语和句式。每一处修改都问三个问题：它解决了哪个具体症状，删掉后会损失什么，后文有哪些地方依赖它。回答不出来的改动通常只是表面变新。

如果是局部修订，优先删去无效重复、恢复原有承接和调整已有材料的顺序，谨慎添加新事实。若是整稿重写，先把原文事实与创作推断分开，原文没有提供的具体人名、地点、经历、数字和结论不能伪装成原稿内容。

## 先建立有位置的判断

先读作品当前想完成什么，记录愿意跟随、失去定向、感到重复、希望停留却被切走的位置。分清想知道答案和不知道发生了什么；分清事实矛盾、材料不足与个人口味。没有成立的问题就不凑缺陷，值得保留的部分也给具体依据。

长稿结构不明时，可以从实际稿件反向记每场发生的事、人物选择、退出变化、承接条件和读者等待。不要抄大纲代替检查，计划完成的功能可能还没有写出来。该记录仅在当前范围内使用，不能据局部否定未读全书。

整稿带标称银幕时长时按[影视写法与容量](screen.md)初筛；局部请求不扩成整片估时。没有真实读者参与，助手的阅读观察不称读者测试。

## 找造成症状的条件

| 症状 | 优先检查 | 可尝试的最小修法 |
|---|---|---|
| 开头进不去 | 背景遮住关切，必要定向不足 | 提前有效行动，补时地关系 |
| 简介动人正文平 | 期待的体验未在过程出现 | 展开前提独有的场面 |
| 主角只接消息 | 关键选择缺席 | 还给符合能力的回应与后果 |
| 动机突变 | 新条件、利害或经历未建立 | 补选择依据而非传记 |
| 中段重来重去 | 尝试没有留下新条件 | 让资源、关系、义务或理解累积 |
| 看着忙仍无进展 | 事件与核心等待无关 | 接回当前关切，兑现一个阶段 |
| 反转突兀 | 证据缺失、视角越界、规则临加 | 补发现路径，保住旧事实 |
| 有谜却没悬念 | 读者不明白为何在乎 | 建立威胁、利害和应对限制 |
| 高潮没分量 | 终局选择与前文脱节 | 带回已建立的关系和代价 |
| 对手忽然迟钝 | 为胜利取消既有能力 | 让主角有成本地改变对方条件 |
| 误会永不说清 | 沟通成本没有成立 | 允许核实，或建立真实阻力 |
| 关系突然修复 | 承认代替兑现 | 补能改变信任的行为 |
| 强事件后清零 | 身体、心理与资源未承接 | 写出对下一步有作用的余波 |
| 场景像讲课 | 信息只为读者存在 | 接到当前需求或简洁旁白 |
| 对白混同 | 注意、诉求、策略和语域相同 | 分清当下对象与说话办法 |
| 所有人只说短句 | 把克制当固定句长 | 恢复各自呼吸和必要长话 |
| 情绪有名无感 | 关键时刻被概述或重复解释 | 展开必要现场与独有心理 |
| 顺但像通稿 | 缺关系、空间和生活条件 | 用已有具体材料替换空转 |
| 因果清楚像记账 | 所有步骤平均用力 | 调整停留和叙述密度 |
| 沉默手势过多 | 动作没有接收与关系用途 | 删装饰，不为每轮配动作 |
| 情绪写成标签 | 情绪没有进入人物的意图、策略和选择 | 补限制、遮掩与反馈，让反应改变下一步 |
| 台词平直、正确但不能直接用 | 人物只把信息或情绪翻译给读者，缺少策略、声线或对方压力 | 先删无作用的句子，再重做双方目标、回避和每轮策略；做换名测试与朗读检查 |
| 台词都像金句 | 每个人都用同样的机智、短句和反转，人物处境没有进入说法 | 保留人物原有呼吸，按关系、知识、权力和当下代价制造差异；让少数关键句承担分量 |
| 对话有潜台词但读不懂 | 回避没有可推断的依据，信息差被写成谜语 | 补一条更清楚的回应、行动或事实锚点，让读者能从现场推出未说出口的意思 |
| 对手戏各说各的 | 一方的行为没有改变另一方的判断或办法 | 补接收、误解、拒绝或策略调整 |
| 场景塞入太多重点 | 多个表现目标互相争夺停留和注意 | 先保住本场主要变化，其余细节服务于它 |
| 设定不断膨胀 | 新规则掩盖旧条件 | 先用已有规则及其后果 |
| 结尾另起一题 | 新价值取消原有承诺 | 写出旧目标结果或放弃代价 |

同一症状可能有不同原因，表格不是自动裁决。顺利不等于没戏，重复也可能累积意义，先看原文再动笔。

## 台词修订要保住什么

对白改写前先列出必须保留的事实、关系动作、人物选择和作者锁定的原句。改写只改变说法、节奏、回避和承接，不把新经历、新道具、新态度伪装成原稿已有内容。若某句虽然平直却承担必要定向，先换它的进入方式或让它落到冲突里，不能为了显得高级而删掉读者需要的信息。

台词修订后分别检查四件事：读者是否仍能知道当前发生什么；人物是否仍只说自己有资格知道的内容；双方的说法是否体现不同目标和压力；删掉的句子是否把后文依赖一起删断。可以记录“删了什么、把什么压到台词下面、谁的声音靠什么区分、哪些信息仍需保留”，但记录服务改稿，不代替改稿。

## 按影响范围修，不按清单凑轮次

一场戏若同时承担人物关系、信息揭示和外部行动，先找本场最需要被看见的变化。其他内容可以通过已有行动、对方反馈或后果带出；不能让每个情绪都另配一个动作、每个信息都另设一段说明。判断标准是删去某个表现后，人物选择、关系判断或读者定向是否真的受损。
先判断问题在主线、场景、表达还是校对层面。在当前授权内先处理会让后续劳动失效的大问题，再处理细部；局部润色没有权限改主线，就保住事实并提示限制。不要强制每次任务走完六轮。

每项重要修改要知道改哪里、解决什么、保留什么、可能影响哪里。要求改稿时给替换段或改后剧情，不用建议清单代替。新增细节核对权限，现实专业事实没有核验就标假设。

改后追动机、知情、资源、时间和后续依赖。当前范围内补接，超出范围明确指出，不悄悄修改未授权内容。比较版本时把保真、连贯和审美收益分开，不能只因新稿更顺、更短就称更好。

## 把读后反馈转成可以修的问题

有真实反馈时保留读者原话和具体位置，再区分阅读症状、读者猜测的原因、建议的修法。读者说“这里太慢”可能是没有进展，也可能是重复解释；不直接把它翻译成删字。多位读者指向同一处值得重看，但人数不代替文本证据。

意见相反时先看他们谈的是否同一段、期待是否相同。同一处有人嫌快有人嫌慢，可能是关键信息略过而无关手续太多。优先修共同症状，具体解法仍以作者目标和事实为准，不把全部建议逐项拼上去。

没有外部反馈也可依据阅读提出假设，但不虚构读者意见或声称独立验证。

## 改后只回查受影响的地方

局部改动后，重读改动段及其前后承接，重点看人物知情、动作条件、关系变化、叙述视角和声音有没有被带偏。结构调整后，再沿着依赖它的后续节点回查，不必为了形式把整篇重新换词。重写后，将成稿与事实清单逐项对照，确认没有漏掉已锁定内容，也没有凭空增加决定性条件。

## 知道什么时候停

本轮明确问题已在授权内处理，关键依赖已衔接，没有新引入的事实矛盾，剩余改变只是同等可行的偏好时，就交稿。没有发现新问题，不为显示勤奋反复换词。暂时无法解决的材料缺口明确写出，不拿无限修订掩盖。

## 版本收益要用实际任务判断

只有用户要求测试或本轮明确包含评估时才做。静态检查可发现遗漏和矛盾，不能证明创作质量提高。用相同材料、模型与相近设置比较新旧版，展示稿件时隐藏版本、打乱顺序，让用户根据具体作品判断。

可选高风险任务包括：保留“听说”和称呼的局部润色；无争吵的合作场景；愤怒却克制的古装对白；有限视角悬疑；不和解结局；多规则幻想；人物知情的跨章续写；小说叙述距离；双语剧本估时；只诊断不改稿；好句不动；锁定结局下的不同中段；临时构思条件不污染定稿。

分别记录授权、事实、视角、知情、载体和长度等硬约束，以及人物辨识、选择可信度、吸引力和语言质感等审美判断。没有运行的用例只叫待测，同一助手知道版本时的自评不叫盲测。不凭规则数、少量样本或主观打分推导市场表现与普遍提升。

## 用分层修订避免乱改

修订按四个层级推进：先看故事是否成立，再看场景是否有必要且有变化，再看段落和台词是否清楚有声，最后才处理语法、格式和事实一致性。上层未定时，不把时间花在下层的精抛光；下层通过后也不反过来重写已经成立的结构。

每一轮开始时写一句本轮只解决什么，结束时用同一句话判断是否完成。诊断时分开文本证据、合理推断、个人偏好和用户硬约束。多人反馈相反时，先找他们共同感到的阅读症状，再决定是否需要改；一条意见不能自动推翻作者的选择。

## 修改的影响记录

每项实质修改至少留住四个信息：改动解决的症状，必须保留的事实或句子，可能受影响的后文，回查后确认的状态。结构移动、人物死亡、重要台词替换和规则变更要沿着知情、资源、关系、时间、伏笔和结尾回看；普通顺句不必扩大检查范围。

对白专门再过一遍：保留谁想得到什么、谁在躲什么、哪些信息必须让读者拿到；删掉的只是说法，不是必要条件。台词更漂亮但人物更不像、事实变松或后文断掉时，审美收益不能抵消结构损失。

## 什么时候停止

本轮目标已完成，改动没有带来新的事实矛盾，关键依赖已接上，剩余意见属于同等成立的风格选择，就停止。连续几轮只是在换同义词、没有改变阅读问题，说明边际收益已经下降；记录仍未解决的材料缺口，不用继续润色掩盖它。
