# 影视写法与容量

用于电影、短片、剧集的落稿、估时和定长改编。小说字数与阅读时长不套银幕算法。

## 落稿以可表演内容为主

动作写谁在做什么、作用于什么、带来什么影响；不可见动机需要有依据的行为承载。必要基调、空间与环境信息保留，不压成孤立动词。场号、内外景、地点、时段、角色和对白按项目统一，用户未要求时不强加行业排版。

不擅自添加焦段、运镜或视频生成提示词。场景先有目标、空间与行动条件，摄影术语不能补救戏剧机制。

双语与外语沿用确认的发声语言。需要双语阅读可附可删除译文，阅读译文不自动成为第二次发声或字幕。语言未明确且影响容量时，问清最必要信息。

## 标称时长先初筛

整稿诊断、定长创作和实质影响篇幅的改稿，有标称时长时先粗筛；单句校对不扩成全片估时。先辨整片、单集还是当前段落，只拿到一段就只估一段。

给出稿件范围、目标、估算区间和关键不确定项。缺实际台词、语言或动作依赖，不能支持数字时就说明缺口。粗估不自动授权删稿。

普通标称值可用一成粗分明显偏差：下限超过标称的110%，才称当前假设下明显偏差；区间跨110%则可能明显偏差。未触及该线不等于达标，阈值也不是误差保证。

严格上限独立判断。下限高于上限即当前估算已超限，区间跨上限即可能超限，上端不超过上限才是估算未显示超限。100秒上限对应105—115秒估算仍是超限，不能借一成阈值放行。以上都不是成片实测。

## 按播放时间线算

1. 确定稿件范围、发声语言、片头片尾与转场是否计入，记录表演假设。
2. 只计实际发声，数字、缩写和专名按念法展开。语速结合角色、情绪与语言；英语普通对白每分钟约130—170词只能作粗估起点，不直接移用于中文等语言。译文未发声不重复计时。
3. 建立行动、台词、等待、反应和声音的依赖。确实同时进行的区间取较长者；必须听完、走到或操作完成才发生的动作在条件满足后起算，不全加也不全重叠。
4. 留观众辨认、人物反应和物理过程所需时间。已计入动作或对白的反应不再重复加，不统一给每次停顿和场标题加秒数，也不靠无意义等待凑时长。
5. 按播放顺序汇总。两条线世界里同时发生，银幕依次播出仍分别计；只有真正重叠呈现的画声才合并。

必要表格只记段落、实际发声与关键动作、先后或并行依据、估时范围和不确定项。标准排版一页约一分钟只作粗校，蒙太奇、动作和非标准排版尤其不可靠。没有实际试读计时就明确称估算。

## 压缩要真的减少播放时间

先看重复信息、功能重复的尝试、可省手续和可并场景，再评估支线与情绪缓冲。重复若有新理解或累积，不按次数删；少写字不一定少播放时间。

方案按位置说明删并、预计节省、损失与因果补接。同一时间段的方案不重复计算收益，改前改后使用同一假设，不机械交叉相减区间端点。

保住关键选择、必要铺垫、资源取得与辨认时间；确需改动，明确由哪里承接并回查动机、知情与终局。短片缩减信息与人物负担，不能把长篇每一幕平均缩一点。

用户只问能否压短，给具体方案；明确要求压缩就交实际改稿并按同口径复算。保留要求与目标不相容时说明差距，不靠极快念词或虚报秒数声称达标。精确成片长度仍需实际表演或播放验证。

## 先写可表演的戏，再谈镜头

剧本场景先明确谁在空间里、想完成什么、看得见或听得见什么、什么行动会改变局面。摄影术语不能替代人物选择；不能被表演、声音或环境呈现的心理，需改成可观察的行为、语言或结果。一个场景若只有说明而没有行动条件，先回到场景机制。

## 用播放链估算容量

估时不仅计算台词，还要把观众辨认空间、人物反应、行动完成、等待、声音和转场的必要时间放进来。并行发生但必须依次看见的内容仍分别计时；真正同时呈现的画面和声音才可以重叠。压缩时先删重复说明和无效手续，保住关键选择、资源取得、辨认和后果。

## 影视稿交付前

检查每场是否能用可表演内容理解人物目标和变化，场景之间是否有明确的进入与退出条件，台词是否没有承担人物不可能知道的说明，格式是否服务于阅读。时长只称估算，除非已有同口径的实际试读或播放记录。
