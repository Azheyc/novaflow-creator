# 构思与取舍

用于方向未定、候选雷同和构思阻塞。已锁定的事实与本轮权限始终有效；一般正文创作、校对和局部润色不自动启动全套发散。

## 把卡点缩到可以试的地方

先问自己到底缺什么：故事起点、人物下一步、可信的选择理由、能够持续的中段，还是一种合适的讲法。把“这个故事不够好”落成具体问题，例如他不愿求助，却必须接近证人。区分用户已经锁定的内容、仍可发展的空白和自己惯用的解法，优先动后两种。

灵感来自条件相互作用。给的是人物，就找会使其惯常办法失效的处境；给的是画面，就想画面之前的选择与之后的后果；给的是世界规则，就看谁受益、谁承担成本；给的是结尾，就反推必须发生的经历。不需要把一个意象立刻扩成整套世界史。

## 让候选在机制上不同

探索时暂缓审美淘汰，让不同办法走出一小段后果，再归并同类。每条至少说清谁遇到什么处境、采取什么办法、得到或失去什么，以及新条件会把他带到哪里。只改职业、时代和地名，行动链不变，通常仍是一条路。

按请求给候选数量，未指定则少量即可。真正的差异可来自主导关系、信息先后、资源归属、行动代价或收束意味。不要为凑数交同义方案，也不要第一条勉强成立就停止。

| 卡点 | 可试的改变 | 留用前要看 |
|---|---|---|
| 人物总用同一办法 | 改变资源、权限或求助对象 | 限制有来由，没有取消常识 |
| 对手只是拦路 | 推演他不受干扰时的计划 | 计划有收益、能力与约束 |
| 关系只剩敌友 | 调整欠情、误信和共同需要 | 变化有经历与利害依据 |
| 设定只是背景 | 让规则影响取得、使用或分配 | 不只送便利，也改变选择 |
| 点子互不相干 | 让一个结果成为另一件事的条件 | 两者真正相互依赖 |
| 反转只有藏身份 | 改变证据的可信度、用途或解释 | 旧事实保留，揭晓有后果 |
| 场面很大却空 | 把代价落实到一人一事 | 不是仅仅缩小声量 |
| 中段总在拖延 | 改变一次尝试留下的义务与损失 | 下次不能无成本重来 |

## 用试验暴露依赖

可暂设一个条件：便利工具不可用、只能经现有关系求助、关键场景不能靠背景说明。试出办法后撤掉临时条件，看它在原设定中是否仍有价值。需要的话补足选择它的真实理由；只有人物变笨才能成立就舍弃。试验不是定案，不把临时规则带进正文。

也可从失效方向找问题：怎样会使这一托付毫无分量，或使这场追逐无法相信？随后定位造成失效的条件并作最小修补。信任得来太容易不代表必须背叛，拖沓也不代表必须出事故。原方案成立时不继续制造缺陷。

## 选定之后往前写

先排除越权、违背设定和无法容纳的方向，再比较人物选择、后续展开、阅读体验和篇幅成本。取舍可以不止一个维度，不以精确总分假装客观。按用户目标推荐，商业收益和市场热度需要另有真实数据。

只验证最大疑问：声音不明就写一次交流，前提能否持续就推几步互相改变条件的行动，结尾存疑就追关键资源。能正式写作便停止发散。弃案不串入选中稿，试写里的临时事实不自动锁定。用户已经要故事，就继续成篇，不把选题做成额外审批。

## 把候选推进到可写状态

候选不是一句新鲜设定，而是一条能继续产生选择的压力链。对每个保留方向至少向前推三步：人物现在最想保住什么；第一种办法为什么失效或变贵；这次失败给下一步留下什么不能忽略的新条件。三步之后仍只能换地点、换敌人或重复误会，说明它还没有形成自己的机制。

构思时可以同时做两种试验。第一种拿掉最方便的解法，观察人物是否会被迫采取更能暴露关系的办法；第二种提前给出一个看似有利的结果，追踪它会带来哪项义务、误信或资源消耗。试验用来发现依赖，撤掉临时条件后，只有仍属于原设定的部分才进入故事。

选方向时把“最吸引人的画面”与“最能长出后果的机制”分开看。画面负责让人想靠近，机制负责让人物无法轻易离开。两者都成立时优先保留能让人物采取非惯常办法、又不取消其常识和能力的方向。

## 构思阶段的出口

当最大疑问已经有可信答案，人物的下一步能写成具体行动，结尾所需的关键条件有来源，就停止继续发散。仍有多个方案时，不用抽象分数裁决，写出每个方案的第一场和第三步，让人物在过程中的差异替你完成取舍。
