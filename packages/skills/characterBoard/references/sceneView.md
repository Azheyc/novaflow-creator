# 场景资产展示规范 1.4

## 固定交付原则

仅对场景资产使用本规范。每个需制作的场景/状态默认给出一张横向16:9图片的中文提示词：单一机位、单幅连续画面、四分之三全景，完整交代该机位合理可见的主要空间。

将“四分之三”理解为从斜侧方观察的方位，通常较主要空间朝向侧偏约30°–45°；将“全景”理解为主要空间与结构关系整体可读。保留完整场景取景范围，不按四分之三面积裁掉空间。整张图片由一个连续环境画面占满；场景视图数量默认一项，使用 scene_view 与 overview，不套人物或道具资产板布局。

按已知空间选择实际观察点，使主要结构、前后纵深、出入口及关键陈设的相互关系清楚。必要时轻微抬高机位并俯视，以看清地面布局与空间层次；俯视高度服务空间可读性，不自动转成垂直鸟瞰。使用自然广角透视并保持建筑、家具与环境比例可信。

## 事实与展示分开

1. 只消费原文事实、用户指定设定与已确认设计。室内外、墙体结构、地形、出入口、朝向、邻接、陈设位置、时间天气等没有依据时记录 unknowns，不凭模板补造。
2. 将展示方位、机位高度、全景构图、画幅与必要的可读性照明建议写入 presentation，不记作剧本事实或剧情镜头。
3. 场景背景直接呈现该地点的建筑、地面、天空或实际环境，使用对应状态的昼夜、天气与场景光线。保持同图一个时间/天气/破损状态；空间结构固定，状态差异按 variants 分别绑定提示词。
4. 默认展示环境本体和有依据的陈设。人物清单与剧情动作在场次记录中维护；需要比例参照或明确陈设中的人形元素时按用户要求及证据处理，不自动把剧情人物加入空场景参考。
5. 门、神像、树木等按制作与交互需求确定主资产类型：以整体布局与周边空间为主时归场景展示；独立道具的结构视图按 propBoard.md。对象在场景中可保持已知位置，详细定义引用其资产编号。
6. 未知布局影响取景时输出草案与必要占位符，列出待确认项。严格提取模式继续保留已知关系，核心空间设计获确认后才定稿。

## 空间覆盖限制

- 室内从合理斜侧观察点取景，呈现可见墙面、地面与主要陈设关系；完整房间能合理纳入时采用房间全景。
- 室外选择能交代主要建筑/地形与周边关系的斜侧全景，保留前景、中景和远景的已知空间层次。
- 对遮挡、多房间、室内外或巨大场地，先说明单机位覆盖边界。确需多个区块时分别输出独立单幅四分之三全景，记录所属母场景与连接关系；每张图片各自保持连续空间。
- 墙体与实体遮挡按真实空间处理。剖视、屋顶移除或其他展示性结构改动须用户确认，并明确属于制作展示方案，不转成原文事实。
- 同一场景更换机位不创建新资产或新状态；确需独立制作的物理区块才依主流程划分资产。

## 稳定空间与状态变化

地点用能区分的具体名称；同一地点跨场复用有证据的地标、入口、道路和陈设关系。固定地理关系以场内基准描述，观察方位选定后再使用画面左右。昼夜、天气、光源或破损变化仅覆盖对应状态，不重建整个地点。

为相同地点状态补充另一观察方向时，保持物理布局、光源所在位置、色温主次和灯具状态相容；画面左右随相机改变，场内光源方向与结构关系保持一致。未知光源、材质、朝向与尺寸记录待确认，不为解释画面补造。状态卡明确本次变化及其余保留项；详见 `continuityWorkflow.md`。

## 中文正向提示词模板

用已知内容替换方括号，无依据且可省略的项目直接省略；必要缺失信息保留占位符并标记 draft。

```text
[场景名]的环境资产全景图。视觉风格：[用户指定画风]。横向16:9画幅，单一机位的一幅连续场景画面。采用四分之三全景视角，从[有依据的合理斜侧观察位置]观察主要空间，[实际观察高度与必要的轻微俯视]，整体呈现可见的空间布局与前后纵深。

[室内外与已知空间结构]。[主要建筑、地形、墙地面或其他已知环境特征]。[有依据的出入口、相邻区域与关键陈设相对位置]。前景、中景与远景按照已知空间关系自然延伸，主要空间结构清楚可读；取景止于真实遮挡边界。[已知昼夜、天气、场景照明与状态]。

整张图保持同一场景、同一空间布局与同一状态，环境连续占满画幅，主要结构与关键陈设保留合理边界，自然透视和准确尺度关系。[按实际材质呈现已知表面特征]。资产编号与版面说明保留在图外，环境中的原生文字和图样仅按已有依据呈现。
```

四分之三方位以具体空间结构为准，最终提示词只保留选定机位，不堆列互斥候选。未知机位依据、布局或状态写入 pending_fields 与 unknowns；生成设置只给可支持的推荐比例，不伪造模型参数。

## 每张场景卡追加内容

1. 展示方案：场景/版本编号、单幅四分之三全景、机位依据与可见范围。
2. 空间关系：主要结构、出入口、陈设位置与邻接关系的证据及未知项。
3. 中文正向提示词：可单独复制，完整描述一个连续空间与一个状态。
4. 生成设置与完成度：默认横向16:9；用户另给比例时优先遵守，维持单幅全景；ready/draft、关键缺失项与已确认设计来源。

## 人工验收

核对单张图只要求一幅连续环境全景；四分之三是观察方位，全景覆盖主要可见空间；机位与遮挡关系可信；真实场景背景、光线和状态一致；场景中的道具位置与各资产引用一致；没有通过模板添加原文未知的空间事实。未生成图片时只报告提示词规范审查，不宣称成图已验收。
