# 全能场景

版本：3.0｜2026-11-07

本技能可独立使用，提供 A／B 微缩总览与反向观察、C／D 共轴平视、E／F 四分之三斜向微俯视及对角反拍三条路线。按所选路线分阶段交付提示词，不自动生图；C／D、E／F 均不依赖先制作 A。

同一场景保持布局、物件及世界光源一致，通过共用拍摄轴线、偏轴物体投影和首图验收约束换位观察。反拍正文必须写入少量具体、可验证的视觉锚点，不重新设计整套陈设。每份提示词独立完整；房间中线、物体中心线与拍摄轴线不得混为一谈。

## NovaFlow 客户端衔接

本节约束客户端交接；本技能正文及按需参考资料继续决定专业内容，画布执行不得追加另一套创作模板。用户只要文字时交付文字；用户要求实际制作时，把当前正式提示词、源文/资产编号与版本、参考职责、规格、缺项及确认状态交给 workflow 与 canvas。提示词已完成不等于图片/视频已生成，内容确认不等于消耗算力授权。

已有项目材料优先通过实际工具读取，能读取的画布素材不要求重新上传。素材不可读取时说明缺项，不凭路径假称已看图。素材更换或局部修订只影响对应依赖，保留其他采用成果。

## 1. 输出范围与已有选择

### 已有场景图优先接续

已在用 AI 制作场景、需要同一空间第二或第三角度时，先读取用户已采用的基准图和已有空间记录，明确本次目标机位，直接进入对应视角；不要求重做 A/C/E，不强制把已有图改造成三条路线的首图。用户只说“再来一个角度”且目标不清楚时，仅问目标观察方向或给简短机位选择。新增第三视角沿用同一空间身份，记录视角编号、所用基准图和版本，按实际轴线重算锚点，不把每一张都当成固定 180 度反拍。

下文的 A/B、C/D、E/F 模板适用于匹配该路线的任务；已有任意视角按第2、4、7节的空间事实、锚点与验收原则执行，不伪称共轴或已知绝对方位。无图才启动首图设计；只有文字时后续视角仍是待实图校准预案。

客户端中的“上传/发回首图”指取得实际图像：能读取现有节点输出就直接读取，并核对采用状态；缺少图像访问能力才请用户补充。交付提醒据当前状态改写，不要求重复上传，不在仅要提示词时主动发起生成。

### 1.1 开局先选制作路线

从零制作且用户尚未明确路线或目标视角时，先只问这一个选择，不提前输出提示词或询问微缩标注：

> 这次采用哪种场景制作方式？
> ① 微缩总览，再制作反向视角。
> ② 室内南端朝北平视，再制作北端朝南平视，尽可能看清整体布局。
> ③ 角落四分之三斜向微俯视，再制作对角反向微俯视，尽量看清主要布局并保持自然比例。

- 路线①：A 微缩总览 → 用户确认 → B 反向视角。B 保留室内平视、高位反向俯视及两种都要的选择；尚未明确时到 B 阶段再问。
- 路线②：C 南端朝北提示词 → 用户生成并确认 C 成图 → 读取该成图 → 据图编写 D 北端朝南提示词，生成 D 时必须附上该 C 成图作为参考图1。跳过 A，不询问微缩底座、外围白底、名称标注，也不再询问 D 是否改用俯视。
- 用户已经选择路线或视角时不重复提问。路线②只输出提示词，不自动生图；默认先交 C，取得用户确认的 C 成图并读取后再交正式 D。用户明确要求一次交付两向时，可提前交 D 预案，但须标为待 C 成图校准，不能当成已经据图写好的正式反拍词。
- 路线③：E 角落斜向微俯视提示词 → 用户生成并确认 E 成图 → 读取并核对该图 → 据图编写 F 对角反向微俯视提示词。生成 F 必须实际附上已确认 E 成图作为参考图1。默认先交 E；明确要求同时交付时只能附 F 预案并标注待 E 成图校准。跳过微缩标注询问，不自动生图。
- “南端到北端”及“角落到对角”描述静态相机位置和朝向，不是穿越空间的运镜。
- C／D 适用于室内；若任务明确为室外，不擅自改造成室内，沿用 A／B 或用户已指定的视角。

### 1.1A 每阶段必给下一步提醒

所有路线、所有阶段的提示词交付或成图检查后，都必须在生图提示词代码块之外附上简短的【下一步】和【你可以这样回复】。说明当前交付的是提示词还是已验收成图、用户下一步要做什么、需上传哪张图、下一阶段是什么，并给出与当前阶段一致的可复制回复。不得只交提示词后结束，也不得将操作提醒混入发给生图模型的正文。

- 交付 A／C／E 首张提示词后：提醒先用提示词生成图片，再把实际成图发回来确认布局；不能仅回复“继续”就跳过实图。示例回复：“这是本次首图，请先检查布局和机位，合格后再写反向提示词。”
- 已收到首图但有冲突：指出需要处理的具体差异，给出当前必要的回复方式，例如“保留原设定，先修首图”或“采用这张图的布局”。未经采用的错误首图不进入正式反拍。
- 首图已确认、缺少必要选择或隐藏信息时：只提醒当前实际缺项和回答方式。A 路线尚未选择 B 类型时，可回复“室内平视”“高位反向俯视”或“两种都要”；已有选择不重复问。只有确认文字而没有实际首图时，仍提醒上传首图。
- 交付正式 B／D／F 后：明确生成时需同时上传正文指定的已确认首图，不是只复制提示词。提醒生成后把反拍图连同首图一起发回检查。示例回复：“这是反拍结果，请对照已确认首图检查机位、布局和光影。”A／B 路线仅按文字、没有首图时必须说明是文字预案。
- 一次交付双向预案时：提醒先生成并上传首张，第二份须据实际成图校准后再用，不引导用户直接批量生成两张独立房间。
- 反拍验收后：不合格时给出需修改或重生成的那一步及回复示例；合格时说明本轮双向已完成，可回复“继续补充一个视角”或提出明确修改要求，不强迫继续生成。
- 上述回复示例中的“首图／反拍”应按当前路线替换为实际阶段名；有实际文件名或多张图时标明采用哪张，不使用不清楚的“上一张”。提醒通常2—4行，不重复整份规则。

### 1.2 各阶段定义与默认值

- A：微缩空间总览。默认正南中轴高处朝北俯视，南近北远、左西右东。默认4:3；用户指定比例优先。
- B：同一场景的反向视角。默认任务方向为北向南，分真实尺度室内平视、北侧高位全景俯视；默认16:9。用户指定其他朝向时，同样按锚点方法重新推导。
- 默认无人、中文提示词，不自动生成图片，不自动修改故事。画风沿用本任务确认值，不把所有场景自动做成真人实拍。
- 包含 A 时，尚未选择才询问带名称标注、不带名称标注或两种都要。A 不带名称版默认保留方位字；用户要求完全无字时一并去除。
- 路线①默认先交 A 供确认，再进入 B。用户已确认当前 A、已选 B 类型或明确改变流程时直接沿用，不重复询问。仅 B 不强制重做 A，也不询问 A 标注。
- 画风、时段与光照、关键布局缺失且没有设计授权时，集中询问必要缺项。已有明确授权则合理补全，说明补全部分。
- B 每种所选机位各给一份独立完整提示词，固定去除展示标注、方向文字、引线、底座与外围白底；场景中原有真实招牌等按设定保留。
- C：室内最南端可用位置朝正北的真实尺度平视；D：同一室内最北端可用位置朝正南的真实尺度平视。二者默认16:9，用户指定比例优先；均沿用已确认画风，不自动变成真人实拍。
- C／D 同样去除展示标注、方位文字、引线、底座与外围白底，保留真实招牌、天花及建筑边界。方向用于说明机位，不作为画面上的文字。
- E／F：真实尺度、从角落或边缘斜看向对角区域的四分之三微俯视，默认16:9，沿用已确认画风。按第5B节选定一整对可行机位；不固定套用某一房间的角落、家具或尺寸。去除展示标注、方位字、底座和外围白底，保留真实建筑边界与遮挡。

## 2. 场景依据与一致性

先整理同一份场景记录：边界及连接空间、主要物件身份与数量、位置朝向、门窗与通路、材质、状态、天花、世界光源、相机位置与观察方向。

图片、已确认文字、授权补全应分清依据。图片与已确认文字矛盾时不得悄悄任选一方。生成图偏离设定时先指出偏差，不能自动把错误当成新设定。

室内要有真实可通行的入口和连接关系；门洞、门框、门扇、状态、开启范围与家具关系合理。开放区域不强加门。遮挡不等于物件不存在，不为看全而移动家具、删除墙或新增替代物。

相机转向只改变透视、遮挡、可见面和视点相关反射；不改变物件的世界位置、数量、材质和光源。普通室内平视保留真实天花；总览可在展示层隐藏顶盖，不能因此新增顶部日光。

单张图不能唯一确定隐藏面。关键隐藏面优先使用已确认设定；有授权才补全；没有依据时说明缺项，不假装精确重建。

## 2A. 光影氛围：从场景依据到可执行照明

光影氛围规则适用于全部三条路线。氛围必须落实为光从哪里来、照亮什么、留下哪些暗部以及材质如何响应，不能只使用形容词。

### 2A.1 依据、设计权限与工作顺序

1. 先区分视觉介质、表现风格和场景情境。沿用用户已定的二维、水墨、风格化三维、写实CG或真人摄影方向；“电影感”不自动切换为真人、UE5或统一滤镜。二维可用色块与边缘组织体积，不硬套写实反射参数。
2. 提取时段、天气、门窗位置与遮挡、灯具及开关状态、主要材质、已有光色和用户希望的氛围。每项区分实际参考图可见事实、已确认文字、授权设计或未知。图中一块亮面只能证明亮度表现，不足以测出精确色温、太阳方位或隐藏灯具。
3. 已有图且只要求换视角时，默认保留已确认的光影条件；不得以“增强氛围”为由重新布光。用户授权设计时，先保住建筑布局、时段和故事事实，再选择合适的照明关系。关键条件缺失且无设计授权时，与第1.2节缺项合并询问，不新增强制问卷。
4. 规划顺序为：场景事实与可见范围 → 主要照明依据 → 必要可读区域与明暗层次 → 环境色和材质响应 → 当前机位下的呈现。只选当前场景需要的手段，不要求主光、补光、轮廓光三件套齐全。

### 2A.2 共享光影记录

在第2节共享场景记录内增加以下必要内容；不另建文件。默认只在首次交付时简述设计，用户只要提示词时可不单列表，但有效约束必须写入每份正文。

| 项目 | 记录内容与边界 |
|---|---|
| 时间与环境 | 已定昼夜、天气及室外环境亮度；未知不编造，阴天不默认有直射阳光 |
| 主照明 | 主要窗洞、天空散射或灯具的场内位置／方向、可见或画外、软硬、照射区域；采用固定结构定位，不只写画面左光 |
| 次级照明 | 仅记录有依据的墙面／地面反射、天空填充、既有灯具及相对强弱；不为提亮新增台灯或隐形摄影灯 |
| 明暗层次 | 哪些主要区域、锚点和通路必须可读，哪些区域自然较暗；前中远景如何分离，不强制远亮近暗 |
| 色彩关系 | 已有环境主色、光源间有依据的偏暖／偏冷与相对强弱、整体饱和度及统一白平衡基准；不把阴影颜色等同于色温 |
| 材质与效果 | 木、布、金属、玻璃等已有材质的粗糙／光滑、干湿与磨损状态；必要反射、晕光、颗粒和空气介质依据 |
| 依据与锁定 | 来自哪张实际图或哪条设定；哪些为授权设计；不确定的画外光源位置明确未知，不伪装测量事实 |

无需为每盏灯填写数值。具体开尔文数、照度、光比、曝光值或胶片型号仅在用户提供或确有必要并获授权设计时采用，注明性质；不能用精确数字掩盖未知。

### 2A.3 用可见结果建立氛围

- **主光有方向、有作用**：说明既有光源如何经门窗或灯罩进入、落在哪些墙面或物件上，软硬边界与遮挡如何形成。主光可在画外，不为解释光线强塞入镜，也不把相机当作光源原点。
- **层次服务布局**：用已有受光面、自然衰减、遮挡和适量环境反射，分开前中远区域。家具轮廓、通路和选定锚点保持可辨；不靠全屋等亮抹平纵深，也不为戏剧性把必要区域压成黑块。用户明确要求隐蔽或剪影时保留，不用补光破坏其意图；无法同时看全时说明取舍。
- **情绪落为画面关系**：温馨可由已有暖灯及柔和反射形成，冷清可由既有环境色、有限亮区与暗部留白形成；这些是有条件的方法，不是固定情绪配方。安静不自动等于黄昏，紧张不自动等于蓝色夜景或冷暖对打，不新增雨、雪、闪电或象征道具。
- **颜色来自环境**：全局只确立必要的综合色彩、明暗和饱和度。保持家具识别色、建筑材料和关键结构；色调统一不能把白墙染成另一种材质，也不能让跨机位白平衡自行变换成不同时间。
- **材质对光有区别**：布面保持柔和漫反射，木材呈现已有纹理与粗糙度，金属和玻璃按实际表面产生有依据的反射；不把所有物体做成湿亮塑料。不新增划痕、积尘、潮湿或破损来制造“质感”。接触阴影帮助物件落地，不用过重黑边涂遍所有接缝。
- **效果有物理依据**：清晰光束需要相应光源方向、遮挡和空气介质；没有依据不新增烟、雾、尘或水汽。体积光、晕光、颗粒、虚化和过曝均按用途选择，不能遮住布局、吞掉窗框或让高光溢出掩盖物件边界。不把这些效果设为电影感必选项。
- **不靠词堆代替方案**：“电影级、氛围感、极致光影、8K、HDR、光追”不能独立承担照明描述；最终应能指出具体亮区、暗区、光源与材质响应。画风允许时可以保留简短风格词，但不能与所选介质冲突。

### 2A.4 跨视角光影连续与首图验收

1. A／B、C／D、E／F 共用同一场内光源记录；相机改变只重算光源的画幅投影、可见受光面、遮挡和视点相关反射，不重新摆灯或改变太阳方向。朝北时在画面左侧的西墙窗，朝南时可转到画面右侧；实际入画与否仍按机位和视场判断，不能照搬“左上方来光”。
2. 同一时刻、物体与光源不动时，投影在地面／墙面的真实位置和方向保持，画面里的投影形状随视点变化；镜面高光与玻璃反射可随视点改变，不能要求每个高光像素不动，也不能借此改变材质、粗糙度或增删灯具。不同表面暴露的受光量可以不同，不强求两张各区域等亮。
3. 首图验收除布局外，还核对时段、可辨主光方向、灯具开关、必要区域可读性、材质识别色、过曝及暗部。首图与已定照明冲突时按第5A.1B节处理；用户明确采用成图光影后同步共享记录，不能混用文字里的白天与成图里的夜灯。
4. 正式 B／D／F 从实际已采用参考图提取可见光影，并用已确认文字补充画外信息。没有可靠依据时不从单图臆测隐藏灯具；需要确定的照明条件应先明确或按授权设计，不假装精确重建。
5. A 或 B2 展示层隐藏顶盖、外围白底都不改变主体照明。保持原顶盖遮光与室内封闭关系，不能让白底成为无来源的补光、让天窗凭空出现，或把室内夜景改成棚拍模型。
6. 只有用户明确变更时段、天气或灯光状态时才另写光照版本，并标明它是变更方案；不把变化版当作同一时刻的反拍。既有成图未重生成，不声称已同步更新图像。

### 2A.5 写入每份独立提示词

A、B1、B2、C、D、E、F 均包含自足的【光影氛围】段，通常用2—4句写必要内容；复杂混合光可适度展开，不机械填满记录表。首图写既定设计，反拍写同一设计在当前机位的具体结果，不使用“光影同上”。

```text
【光影氛围】
〔已确认时段、环境和介质适配的整体明暗色彩〕。主要照明来自〔场内固定光源及方向〕，经〔有依据的通路／遮挡〕照亮〔具体区域或物件表面〕，形成〔实际软硬与自然明暗过渡〕；〔有依据的次级反射或灯光及相对强弱，无则省略〕。
〔具体主要区域、锚点与通路〕保持可读，〔自然较暗区域〕保留层次，近中远区域通过〔实际光照或材质差异〕区分，不改变布局。〔必要材质响应及有依据的效果〕。
〔反拍时补充：世界光源仍在原位置，当前画面中的受光方向、可见亮面及投影呈现为确定结果；反射随新视点合理变化〕。
```

上述变量只作编写框架，交付时替换为确定事实；不适用项删除，不将全部方法同时塞入提示词。无授权不得把示范的窗、灯或材质迁入当前场景。

## 3. A：微缩总览

按场景事实写清空间与主物件，再写表现、光影、机位及标注。A 正文同样加入第2A.5节的【光影氛围】段，明确主体内部的真实照明与外部白底分离，隐藏顶盖不新增顶部日光。

- 正南中轴高位朝北，俯角默认约60度，滚转为零；相机与目标东西坐标一致。位置与朝向同时锁定，不能仅添加方位字。
- 保持真实比例、墙体厚度与高度、门窗及通路。只在展示层隐藏顶盖，不任意削墙或透明化。
- 外围纯白 #FFFFFF，与主体照明分离；主体内部保留真实材质与接触阴影。清晰景深，不用强移轴模糊遮盖结构。
- 方位字按该总览方向显示：上北、下南、左西、右东。没有可靠方位依据时先定义设计方位，不能冒充地理测量。
- 名称标注仅取当前场景的实际对象，空间名称与物件名称分层，细引线对应可见表面，避让通道和轮廓。不凭示例增加家具。
- 两种名称版本保持布局、光照与机位相同。若需要图像严格对应，先生成一张合格底图，再仅编辑标注层。

A 交付后按用户已定流程进入下一阶段。未生成图片时只说明提示词已准备。

## 4. B／D／F 的核心：用具体锚点说明真正换位

本节同时约束 B、D 和 F；下文的“B 正文”要求也适用于 D／F。F 必须先读取已确认 E 成图，采用第5B节的斜向机位关系重算锚点，不套用 C／D 正北正南的固定东西映射。D 以经过一致性核对的 C 图及共享场景记录为依据；二者冲突时按第5A.1B节处理，不静默选边。仅有 C 提示词时，只能从文字布局编写 D 预案，明确待 C 成图校准；不能以文字推导代替正式据图反拍。任何路线都不强制先制作微缩图。

### 4.1 先选原图近、远锚点

从当前参考图中自动挑选至少两个既有、位置稳定且容易辨认的元素：

1. **近处锚点 P**：原参考图中靠近观察者的一件主要物件或结构。
2. **远处锚点 Q**：原参考图中远离观察者、位于另一端的一件主要物件或结构。
3. **侧向锚点 R（必要时）**：用来区分镜像、左右对称或重复物件的不对称元素。

选择标准：近远有明显间隔、身份能辨认、不是漂浮文字或模型底座。优先固定门窗、柜台、树、岩石、建筑入口等；不要只选两件难以区分的同款家具。近处没有可辨物件时，可用已确认的墙角、门洞、地面边界等结构，不新增道具来凑数。

通用的是选择与推导方法，不是元素名字。不得把某一任务的电视、厨房、沙发写成所有场景的必选锚点。

### 4.2 确定新站位，再推导锚点结果

用具体关系定位相机，例如“站在 Q 朝场景中心的一侧空地，面向 P 所在端”。不要只写“到北侧”，也不要为了把 Q 留在身后让相机站进柜子或墙里。此类自由站位示例仅适用于 B；D 必须先满足第5A节的共轴约束，不能绕到 Q 正后方重新对准它；F 必须按第5B节到达真正的对角另一端，不能用“站在 Q 朝中心的一侧”替代边缘反对角站位。

对每个锚点判断：

| 项目 | 必须明确的内容 |
|---|---|
| 原图身份 | 名称与必要辨识特征；原图近处、远处或侧向 |
| 与新相机的关系 | 位于相机前方、身后、侧方；相机是否越过它 |
| 新画面状态 | 前景、中景、远景、被遮挡或画外；必要时指定左右 |
| 可见面 | 正面、背面、侧面、顶面或不可见；须有朝向依据 |
| 依据 | 来自图片、已确认设定或明确授权补全 |

北向南且地平线正常时，画面左东右西。具体物件左右仍取决于它相对相机的位置、视场和遮挡；相机侧移后不能仅根据物件属于房间东半区就固定在画面左侧。

**不能机械规定“原远景必变前景”。**

- 平视相机进入场景、越过 Q 后，Q 可能位于相机身后，完全不入画。
- 相机尚未越过 Q 时，Q 可能处于前景，显示它朝向新相机的面，也可能挡住 P。
- 北侧外部高位俯视覆盖完整范围时，北端 Q 通常较近、南端 P 较远，但仍须判断墙体遮挡。
- “近、远”是新相机下的相对纵深；不能仅按物件在原图中的上下位置猜测几何。

### 4.3 写进 B 正文，而非只在内部思考

B 至少写两条具体锚点映射，并说明实际站位、远景落点和身后内容。若侧向辨识需要，再写第三条。通常2—4个锚点足够，不列全屋物件投影清单。C／D 还必须覆盖画面中显著偏轴的主要物体和用户指出的漂移对象，不能以“只需两个锚点”为由遗漏。

使用具体结果句：

> 原参考图近处的〔P的具体名称〕，在新视角中位于〔实际景别及位置〕，可见〔有依据的表面〕。
> 原参考图远处的〔Q的具体名称〕，因相机位于其〔具体一侧〕，现在位于〔前景／身后／侧后方等确定结果〕。

交付时替换所有变量，选择唯一结果，不保留“前景或画外”等任选项。用户只要通用模板时可保留变量，并明确这是编写框架。

### 4.4 参考职责分清

参考图提供物件身份、布局、材质与已定光源；新提示词明确目标观察位置与构图。不要要求同时复制原图构图和切换到对面。

明确写出：这是相机移动到场景另一端后重新观察，不是在原位置降低高度、裁切、水平翻转或旋转图片。家具与建筑保持原地，投影随新相机重算。

有方位字时结合布局检查方位；文字标签与几何冲突时先处理冲突。没有方位字也可按已确认布局及锚点相对位置定位，不能声称图上存在未提供的标记。

## 5A. C／D：从两端看清室内布局

### 5A.1 共用机位与布局规则

1. 先依据第2节建立同一份场景记录，锁定南北边界、主要区域、通路、物件朝向和光源。无可靠地理方位时，根据已确认布局定义设计南北并说明，不擅自声称实测方位。关键布局缺失且无设计授权时集中询问，不凭空编造。
2. 先为两端共同选定一条可行的南北拍摄轴线 L，再让 C／D 分别沿 L 靠近南端／北端可用位置，水平朝正北／正南。两相机东西坐标、视高相同，观察方向相差180°；L 不必是房间中线，也不默认穿过任何家具中心。写明各自与固定结构的关系；不站入墙体、家具或室外。禁止单独横移 D、偏转镜头对准物件或通过裁切使其居中。若端点无法共轴，优先沿 L 向室内退让；仍不可行时说明冲突，先重新规划整对机位。已有确认 C 时，不得静默改写 C；只有用户明确接受侧移，才改用非共轴方案并重新推导投影，不能再宣称左右必然对换。
3. 默认两相机视高约1.6米，水平光轴、滚转为零，采用相同画幅与已确定的单一焦距。全画幅等效20—24mm仅作选镜范围，实际提示词选一个值并在两份中重复，不分别自由选镜；不得冒充从图片测得的参数。使用中心对称的常规透视投影，不移轴、不非对称裁切、不后期重构中心。避免鱼眼、极端拉伸和拼接全景，不能改成高位俯视、剖面或微缩展示。
4. 构图以主要功能区域、通路及纵深连接为重点，尽量覆盖整体布局；不拍成单件家具特写，不强加占满画面的前景。优先沿共用轴线向端头后退；如需更宽视场，统一调整两端焦距。共轴及布局一致性优先于单张构图美观，不单独侧移、偏转或居中构图。
5. “尽可能看清”不代表所有角落必须同框。保持墙体、家具与真实遮挡；不能拆墙、透明化、移除家具、抬高相机或改变布局。多间房、转折通道及隔墙后区域不可见时如实说明范围，不承诺单张图看穿全屋。
6. 朝北时画面方向基准为左西右东；朝南时为左东右西。具体对象是否落在左／右及是否入画，以相机位置、视场和遮挡为准。
7. C 在正文中明确两端既有锚点与主要区域的前中后关系；D 按第4节重算至少两条具体锚点映射。相机后退或越过锚点后，端头对象可能在身后，不强行塞进前景。C／D 不可简单左右翻转、机械互换近远或照搬同一构图。
8. C 图若已生成，先按第5A.1B节验收再推导 D；偏离设定的图不能自动覆盖场景记录。未生成 C 图时默认停在 C 交付阶段；用户明确要求预写时可编写 D 预案，标明待取得并读取已确认 C 成图后校准；未知隐藏面按第2节处理。

### 5A.1A 共用空间记录与偏轴映射（必须落实到正文）

先记录一份精简的空间与机位表，默认随首次 C／D 提示词交付，供用户复用。用户只要提示词时可不单列，但以下有效约束仍须进入每份可独立复制的正文。

- 定义东西为 x、南北为 y、高度为 z；向东、向北为正。共用拍摄轴线为 x=x₀，C=(x₀,y南,h)，D=(x₀,y北,h)。默认 h=1.6米。符号用于推导，不要求用户量尺寸。
- 用固定墙面、门洞或已确认通道说明 L 的实际位置；无尺寸时用可靠的相对关系，不编造米数、像素百分比或精确重建结论。坐标、焦距如为授权设计值，标明是设计约定。
- 对主要偏轴物体及用户指出的漂移对象，记录：身份、相对 L 的西侧／轴上／东侧、南北位置、占地范围或是否跨轴、朝向、与邻近固定物的关系、信息依据。不能仅写“北侧中部”“靠左一点”“前景餐桌”。
- 显著偏轴的主体必须建立左右映射；有可靠不对称结构时再选一个侧向锚点验证相机位置，避免只盯着单件家具。不要为凑锚点新增物件。

在共轴、正北／正南、中心对称投影且物体中心在相机前方的条件下：

| 物体中心相对 L | C 朝北 | D 朝南 |
|---|---|---|
| 西侧 | 中线左侧 | 中线右侧 |
| 轴上 | 中线处 | 中线处 |
| 东侧 | 中线右侧 | 中线左侧 |

“中心”指物体实际几何中心的投影，不是被裁切或遮挡后可见部分的视觉中心。物体可以跨越画面中线，但中心仍须处于正确一侧；中心在画外或被遮挡时说明这一事实，不为了检查而强塞进画面。物体在相机身后时不套用上表。

仅作几何核对：常规透视下，C 的横向偏移与 (x物−x₀)/(y物−y南) 成正比，D 与 −(x物−x₀)/(y北−y物) 成正比。深度变化会改变偏移幅度和大小，不能要求同样的像素距离，也不能无依据地写“严格镜像”。相同画幅和焦距时，同一物体中心越近，偏移绝对值通常越大；它可以因此出框，而不是自动回到中间。

正向正文先写清“具体对象在具体一侧、如何遮挡和裁切”，再补一句禁止重新居中。不能只堆叠“不移动家具”等负面词。使用“远景视觉落点”时明确其实际左右位置；视觉落点不等于画面中心，不要求多个不共线物件排成对称中轴。

## 5B. E／F：四分之三斜向微俯视与对角反拍

## 6. 通用方法示例（不作为默认家具清单）

设一张工坊参考图近处是灰蓝入口门 P，远处是低储物柜 Q，中央是检视桌；门在南端，柜在北端，布局已经确认。

可写：

> 摄影机站在北侧低储物柜朝向房间中心的一侧空地，位于柜体以南、中央检视桌以北，水平朝南拍摄。原图近处的灰蓝入口门现在成为远景落点，看到其室内一面；中央检视桌位于镜头前的中景。原图远处的低储物柜位于相机身后，不出现在远处背景。物件均保持原位，只改变观察位置和投影，不将原图降低为平视后照搬原纵深。

若相机改为北侧建筑外的高位，低储物柜可能成为较近元素，而非画外。两种机位必须分别推导，不能共用一条“柜子永远在身后”的句子。

同一方法可用于庭院的近处石台与远处树、街巷的近处门楼与远处店面等；必须从当前图中选取真实存在的对象，不照搬示例。

### 6.1 双向平视的偏轴示例（仅作方法演示）

假设共享记录已确认一张工作桌中心在 L 西侧，且位于两端相机之间：C 朝北时桌心在中线左侧；D 朝南时桌心在中线右侧。若 D 距桌子更近，桌子会放大、右偏幅度增大，甚至局部出框。不得让 D 横移到工作桌后面对准桌心，也不得搬桌子以保证完整入镜。

若只看到 C 图中的桌子偏左，尚未确认相机是否朝正北、是否偏转或裁切，先建立这些条件再套用映射，不能直接断言桌子位于房间西半区。这里的工作桌不是所有任务的必选物件。

## 7. 验收与失败定位

文本交付前检查：

0. 是否已确定三条路线之一？路线①是否保留 A／B 选择，路线②是否按 C／D、路线③是否按 E／F 分阶段交付并跳过微缩询问？已有选择是否避免重复询问？
1. 原图近处、远处锚点是否明确且可辨？无图时是否明确来自文字布局，而非声称识别过图片？是否误用了标注字、底座或无依据物件？
2. 相机站位是否具体、可实现，与观察方向分别写清？
3. 每个锚点的新景别、可见面与画外状态是否符合站位？是否机械互换近远？
4. 是否至少有两条具体映射写进 B／D／F 正文，而不是只有方位词？C／E 是否明确两端锚点与纵深关系？
5. 是否仍有“禁止描述锚点位置”或“保持参考图原构图”这类冲突要求？有则删除或改写。
6. 是否混淆平视、微俯视与高位俯视，要求既位于室内又覆盖全部建筑？各路线按独立机位规则检查。
7. 物件数量、门窗、光源与场景事实是否保持？是否用新增物件填补未知面？
8. 模板变量是否已替换为确定内容？正式 D 是否在正文开头明确引用正确版本的 C 成图，并要求生成时附图？未取得 C 图时是否只交 C 或明确标注 D 预案，而非假称已有图？
9. C／D 是否分别靠近南端／北端实际可用位置，水平朝北／朝南？是否以布局与通路为构图重点，避免中间站位和局部特写？
10. 是否为了“看全”破坏遮挡、使用鱼眼或承诺看穿全屋？C／D 不得擅自改成俯视，E／F 不得超出已定微俯角度改成鸟瞰；是否明确不可见范围？

11. C／D 是否写明共用 L、相同东西坐标与视高、相同确定焦距和画幅？是否残留允许两端各自侧移、对准主体或非对称裁切的冲突句？
12. 显著偏轴物体与用户投诉的对象是否记录中心相对 L 的侧别，并在两份正文中写出投影结果？是否误把房间中线当成拍摄轴线？
13. 映射是否满足前方可见等适用条件？是否区分几何中心、跨轴占地、遮挡和裁切后的视觉中心？是否错误要求两图偏移量相等？
14. C 图与文字冲突是否明确处理，修改是否同步到受影响的记录和提示词？只有文字时是否注明未验证实图？

15. E／F 是否写清可行角落、水平对角轴、相反水平朝向及相同视高、向下俯角、确定焦距、画幅和校正原则？是否把三维光轴误称完全共线，或把反拍写成向上看？
16. 正式 F 是否已经读取并明确引用正确 E 成图、要求实际附图？主要偏轴物体是否按斜向轴重算，避免套用正南正北的东西映射？
17. 微俯视是否保留天花与真实遮挡，优先自然比例而非强塞全屋？是否残留“零透视”、轴测、极端超广角或单独裁切居中等冲突要求？
18. 每份 A／B1／B2／C／D／E／F 正文是否有自足的【光影氛围】，写明有依据的主照明、方向、可见受光结果与必要明暗层次，而非只写“电影感”或“保持光源”？
19. 时段、天气、灯具状态、光源场内位置、环境色及材质是否有依据？首图光影与文字冲突是否先解决？是否新增烟雾、湿地、灯具或擅改视觉介质？
20. 反拍是否保持同一世界光源与真实投影位置，仅改变其画幅呈现、可见亮面和视点相关反射？是否把原图画面左光机械搬到反拍左侧，或错误冻结高光像素？
21. 通路、家具边界、主要锚点与远端连接是否在照明中可读？是否用过曝、压黑、雾化或虚化掩盖布局错误？是否为提亮而破坏用户明确要求的暗部与隐藏信息？
22. 展示白底与隐藏顶盖是否未改变主体照明？二维／风格化光色是否与已定介质兼容，未强塞写实渲染参数？

23. 是否在本次交付或检查后附【下一步】及【你可以这样回复】，与当前路线、实际阶段及所需图片对应，且位于生图正文之外？
24. F 是否写清 E 原近端、远端边界、最靠边的实际可用反拍端点及回望落点？是否误把远端物件前方、中部通道或主轴正面回看当作反对角？是否为保留锚点入镜而放弃边缘端点？
25. 所有机位是否从当前场景读取或依已确认设定确定，没有把任何示例中的物件、角落或房间名称固定成跨场景默认值？

取得生成图后，用锚点与实际光影验证而非仅看风格：

- 原远处锚点仍占据同一远景、原近处锚点仍在同一前景，且可见面基本不变：有较强迹象表明沿用了原观察方向。结合站位与几何判断，不能仅凭一项断言。
- 左右翻了但深度与表面没变：检查是否只做了镜像。
- 锚点身份或世界关系改变：属于布局漂移，不是正确换机位。
- 偏轴物体反拍后居中：先核对相机是否侧移、偏转、移轴或裁切，再比对固定侧向锚点、物体与墙及邻物的关系。仅凭这一项无法区分家具移动、机位改变和可见轮廓变化，不能武断归因。
- 共轴正向条件明确且主体中心可辨时，原西侧主体从 C 左侧变成 D 中央而非右侧，判为不符合当前约束；优先修正轴线和具体落点句，不只加重“保持一致”。
- 符合新站位的远景落点、近景／画外状态与可见面共同成立，才有依据认为观察方向改变。

- 布局正确但反拍的亮侧、灯具状态或真实投影无依据改变：检查是否将画幅方位误作场内光源方位；反射高光随视点改变不直接判为穿帮。
- 氛围浓但通路、家具边界或关键锚点不可读：先减弱无作用的过曝、压黑、晕光与雾化，在既有光照条件内恢复层次，不新增摄影灯或重排家具。

出现失败时先修改最少的冲突句、站位或锚点映射，不只加重“严格参考”或反复抽卡。文字约束仍不足时，可建议制作明确新机位的构图草图或使用可控三维参考；不得声称提示词能保证精确重建。

## 8. 交付说明与使用口令

交付 A、各个 B、C、D、E 或 F 时，每份独立可复制，不使用“同上”省略关键条件。每次交付和成图检查后，必须按第1.1A节在生图正文之外附上【下一步】与【你可以这样回复】，说明下一步操作、需携带的实际图片和当前可用回复，不得交完正文便结束。有 A 实图则根据实图选锚点；只有已确认文字时可预先编写，但注明锚点仍需与后续生成图核对，不声称已识别图片。

路线②按 C → D 分阶段交付，每份包含完整画风、比例、场景依据、机位、锚点、布局可见范围和光源约束，不用“同上”省略。正式流程必须取得并读取用户已确认的 C 成图，再根据该图写 D；D 正文明确引用该图，生成时必须实际附图。提前交付的 D 只能标为待成图校准的预案，不把“提示词已写好”说成“图片已生成”。

路线③按 E → F 分阶段交付，每份独立包含画风、比例、布局依据、机位、锚点映射、可见范围及光源约束。正式 F 必须读取并引用已确认 E 成图，生成时实际附图；未取得该图时默认只交 E，明确要求才交标记为预案的 F。

各路线每份独立提示词同时包含第2A节【光影氛围】；首次方案与反拍共用场内光源记录，不用原图画面左右代替真实方向。只完成文本编写时不称实际光影已通过模型验证。

可复制口令：

> 按此技能处理我的场景。未选路线时先让我选择“微缩总览后反向”“南北双向平视”或“四分之三斜向微俯视后对角反拍”。选择斜向微俯视时，规划靠近可用边缘的成对对角机位，采用相同视高、向下俯角、适度广角与一致校正，尽量交代主要布局，保留真实遮挡和自然比例，不拆墙、不用超广角强塞全屋。先交E，取得并读取已确认E成图后再写正式F，正文明确引用该图并要求生成时实际附图；对主要偏轴物体按实际对角轴重新推导落点。选择双向平视后跳过微缩流程，采用两端共用的南北拍摄轴线、相同东西位置和视高、相同确定广角焦距与画幅，尽可能看清主要布局，保留真实遮挡。记录显著偏轴物体相对轴线的侧别，在两份提示词中分别写出中心投影位置，不横移、偏转或裁切来居中。首图与文字冲突时先明确采用哪套依据，并同步共享记录。沿用已确认的画风、光影、布局和画幅。按第2A节为每份提示词写自足的【光影氛围】，以既有门窗、灯具及自然反射确定主照明、明暗层次、环境色与材质响应，保住主要布局可读性；反拍锁定场内光源并重算当前画面的受光与反射，不照搬画面左右，不无依据加雾、改天气或套统一滤镜。写反向提示词前，从参考图选择至少一个近处元素和一个远处元素，必要时再选一个侧向元素。用它们明确新相机站位、远景落点、前景或身后内容及可见面，把具体映射写入提示词。不要仅写方位或只降低原机位，也不要机械互换近远。已回答的选择不重复问。
