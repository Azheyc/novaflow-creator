# 简版预览、输出模式与完整模板

本文件须与 [路由条件与风格](routingAndDuration.md)、[分镜主流程](storyWorkflow.md)、[素材与对白规则](assetsAndAudio.md)配合。第七步编号与段界、第五步人物注意力、第六步镜长均见分镜主流程。模板中的说明项须填实或按适用条件省略。

## 先确定交付阶段

新建分镜默认先交付简易预览，并说明其用途及其不是完整生成提示词；包含后续完整细化时，按本文件“预览结束说明与确认”附固定说明，收到固定口令或明确等义授权后再交付完整版。纯询问只解释并保留方案及确认状态；疑似错误先核实，修改按流程B的授权边界处理，实际修改后重发受影响范围预览。明确只要预览、流程C纯提取时，说明审阅性质并结束，不附生成口令；明确跳过预览或授权修改后直出时直接交付获准范围的完整版。流程B负责确认与修改，流程C负责已有稿的忠实提取。“预览/完整版”是阅读与执行阶段，“整片连续/单镜独立”是生成输入模式，两者分别判断。

本包关于素材槽位、完整音色、光学参数、双重空间展开、精细时间轴、固定注意事项和输入自足性的字段要求用于完整提示词。预览仍按这些规则检查规划；每镜只在下述两个字段里写出影响审阅的事实，另在逐镜前单列一次素材准备清单。技术展开在完整阶段落实。简版审阅稿不作为完整生成输入，也不自动删改原有执行要求。

## 简易预览版分镜模板（默认首轮交付）

开头标【简易预览版分镜（审阅用，非完整生成提示词）】。新建任务先用简短【时长评估】说明语言、估时依据、约束、总长和结论；其后、逐镜内容之前只列一次【素材准备清单】，按全任务稳定编号列出实际需要的人物/场景/关键道具图片及发声角色音频，已有编号沿用，无对应类别或用户明确不用的项省略。状态据实写“待绑定”（预留槽位尚待绑定）、“已提供”（素材已提供，绑定未确认）或“已绑定”（已确认绑定）；不把已提供当成已绑定，无法确认的状态据实注明未知。清单可分少量行，不强制压成一长行；不增加逐镜第三栏，不随逐镜或文本续批重复。逐段镜数/段长放在各大段标题，不重复长清单。每镜标题用 `大段K-分镜N｜简短事件名`，正文仅有下面两个字段；以分开的段落呈现，镜间留空行，默认不用宽表格、整篇代码块或逐镜分析表。

- **镜头基础信息**：一行写本镜计划时长、景别、观察角度和主要运镜或固定状态。已知镜内景别或视点有关键变化时，简写起止；对审阅有影响的焦段和特殊转场按需补充。普通切换由相邻镜号表示。新建预览的秒数是计划，既有稿的时长及区间沿用原稿的含义；存在素材长与成片占用差异时用短括注区分，不把生成余量计为剧情时长。
- **分镜内容**：把画面、动作、对白、拟音和必要环境声按先后或同时关系合写成自然短段落，直接呈现“谁在哪里 → 怎样行动或说话 → 对方怎样回应 → 切出时什么状态”，按镜头实有内容取用。一般用少量短句，长对白可在这一字段内分行，完整性优先于固定字数；不新增独立声音栏，也不把合写字段再拆回多个小标题。

### 合写与简洁规则

1. **动作与台词就近合写**：使用“人物a面朝人物b问：‘……’；人物b抬眼回答：‘……’”这类直接句式，避免先概述问话/回答、再重复叙述同一行为。完整保留实际台词、说话者及有明确对象时的受话者，实际故事使用原角色名称或明确身份。
2. **先后与并行准确**：同时发生时用“说话时”“一边……一边……”等短语说明，必须先完成才能继续时用“……后”。标点不替代因果，也不把原有并行写成串行；关键动作、接触、道具转移和反应各完成一次。
3. **声音跟随对应事件**：合盖、脚步或撞击等必要拟音贴着发生动作写；持续环境声在本镜开头或末尾简写即可。画外声、旁白、内心独白在词句旁就近标明类型与声源；声音跨镜时保留原声源和接续。完整台词只出现一次或按原词句逐段接续，合并后保持原文；无对白与完全静音分别按实际条件描述。
4. **保留可审阅的空间与注意力**：简写关键人物/道具位置、朝向、在看谁或什么、必要走位和结束状态。左右以画面或已声明的地标方向为基准；说话与操作并行时明确需要的目光转移。复杂空间关系须检查画面投影与人物/地标双参照，不能直接删掉基准；例如“人物b面朝门口；人物a位于b的身体右前方，投影在画面左侧”。已建立且未变化的背景少重复，细化时再补齐双重空间字段。
5. **保留拍法与揭示依据**：关键光线、遮挡、可见证据、视点变化或声音先行确实决定观众何时理解时，在事件发生处简写；一般材质、稳定音色和逐秒执行参数留到完整版。可读性与节奏仍按内容规划，不为简短文字拆镜，也不把多镜合成一条故事梗概。
6. **保持完整与定位**：预览覆盖当前请求的每一个摄影镜头，包括已开启的段末锚点；锚点标注1秒、静止静音、必要空间关系及成片保留/剪除计划，与剧情镜分清。锚点默认关闭。长对白、多人镜或跨镜声音允许更长的内容字段，保住完整台词、关键反应和连续状态。

模板仅示意结构，实际输出填实，使用普通Markdown段落：

```text
【简易预览版分镜（审阅用，非完整生成提示词）】
【时长评估】语言：[成片发声语言及估时依据]；约束：[适用时长/入口限制]；预计总长：[X秒]；结论：[简短结论]。
【素材准备清单】
@图片1（角色：具体角色名）｜待绑定
@图片2（场景：具体场景名）｜已提供
@音频1（角色：具体角色名）｜已绑定

大段K｜M个分镜｜计划段长D秒

大段K-分镜N｜简短事件名
镜头基础信息：计划X秒｜景别｜角度｜固定或主要运镜。
分镜内容：人物的关键位置、动作、完整对白与必要声音按发生关系合写，落到本镜切出状态。
```

外语对白默认在每句原文旁附可删除的“（中文：……）”供阅读；中文不发声、不计时、不匹配嘴型，也不作为字幕，投喂前删除。用户明确要求净版时省略；纯流程C按原文提取，不自动新增翻译或释义。

合写格式示例（秒数仅示意，不作为镜长配额）：

> **大段1-分镜1｜确认准备**
>
> **镜头基础信息：** 计划6秒｜中景｜平视｜固定机位。
>
> **分镜内容：** 画面左侧的桌边是人物a，右侧是人物b。a面朝b问：“准备好了吗？”问话时，b低头合上盒盖，发出轻响；听完后抬眼看a，回答：“好了。”

已有稿转预览使用相同格式，保留原镜号；必要缺项在相应字段标“原稿未说明”。流程C只忠实汇总原有素材映射，不补造缺失映射，不因未知语言或素材状态阻塞提取。实际矛盾在预览正文之后集中用简短待核对说明按原镜号定位，未发现问题时省略；每镜正文仍为两栏，其余按流程C处理。该例的道具、动作与台词仅演示合写，实际故事按原内容填写。

## 预览结束说明与确认

先按任务范围选择结尾；本节属于预览阶段的必读内容。

### 包含后续完整细化的流程B：使用固定说明

仅在流程B任务包含后续完整细化、当前交付范围的简易预览已完整输出，且尚未获准直接进入完整版时，在预览正文之后原样附上以下说明。实际修改后重发的受影响范围预览，也在相同条件下再次附上。说明放在可投喂提示词代码块外：

> 以上是【简易预览版分镜】，供你检查镜头顺序、人物动作和对白是否符合预期；它还不是可直接用于生成视频的完整分镜提示词。确认没问题，请回复【确认，生成完整分镜提示词】；如果有问题，请指出对应大段／分镜号和修改意见。我会先按意见修改，再给你更新后的简易预览；等你确认后，才输出完整分镜提示词。

在上述待细化分支，收到【确认，生成完整分镜提示词】或明确等义的完整提示词授权后，按已确认范围细化。仅回复“确认”或“没问题”代表内容认可，可简短提示固定口令，保持待细化状态；“继续”按当前阶段与已授权范围解释。纯询问只解释并保留方案及确认状态；疑似错误先核实，修改权限与修订后处理按流程B执行。尚未完整交付时，标明已交付及剩余范围，续完当前预览范围后再附固定说明。用户在开场或后续明确跳过预览、一步到位，或授权修改后直出时，按获准范围交付完整版，不新增确认节点。

### 仅预览或流程C纯提取：说明性质后结束

用户明确只要预览时，只说明“以上是简易预览版分镜，供审阅镜头、动作与对白，尚非完整生成提示词”，交付后结束，不附生成口令或要求确认进入完整版。已有稿按流程C纯提取时忠实保留原稿，说明“以上是原完整稿的简易审阅呈现，原完整稿仍为执行依据”，完成后结束。用户随后仅表示认可时，简短回应即可；另行明确要求修改或完整细化时，再按新请求处理获准范围。仅预览任务的返修稿仍使用本分支，修改不自动增加完整细化阶段。

## 输出模式与生成参数（完整细化阶段）

- 完整版默认采用**整片连续模式**；用户明确要求“逐镜生成、单镜独立复制”时采用**单镜独立模式**。两种模式的新建任务均先按当前阶段交付预览，明确跳过时除外。
- “整片连续模式”按整部作品的连续剧情组织交付，一大段对应一份生成输入，可包含一个或多个连续摄影镜头；拆段后每段的镜号与时间按下一则规则归零累计。该模式不等于一镜到底；一镜到底要求一个连续摄影镜头，切镜与拼接须按用户授权处理。锚点默认关闭且不询问、不提醒；用户开启后仅在连续性确需接续且后面还有下一大段时，于适用大段末加1秒，最后一大段默认不加，明确留末段参考/续写时可例外。单镜独立模式按大段接续判断，不逐镜加。生成输入含完整1秒，成片仅计保留部分，按实际锚点数及保留方案重算总占用，不设固定每K段增加K秒；开关变化按授权重算受影响段和编号，不压缩剧情。
- 时间区间统一写为秒数表达，如 `0秒到3秒`、`3秒到4.5秒`；超过一分钟时继续累计为秒数，如 `60秒到64.5秒`。整数端点直接写整数；有实际需要的亚秒端点保留必要的小数精度，不补无意义尾零，不将小数精度等同于生成精度保证。
- **时间按输入归零，镜号按大段归一**（编号与段界细则见第七步）：每份独立输入从 `0秒` 起算，同一输入内切镜继续累计；每个新大段从 `分镜1` 起算；同一输入的文本续段两者都不重置。成片全局位置只放在代码块外；整片一次生成且无剪取时，全局与局部数值自然一致。归零仅消除参照歧义，不承诺防止死帧或丢帧。
- **信息分层放置规则**：大段号、段内镜号范围、跨段索引（如 `大段2-分镜3`）、成片全局位置、实际段长、生成时长参数、剪取映射与后期剪辑说明放在代码块外；块内保留该次生成实际需要的画面、动作与声音。确认预览且范围未变时，评估块外一句“沿用已确认预览的时长评估”；部分细化不得把部分时长标作全片时长。整片连续模式的块内分镜标题使用本段镜号与本次输入的连续局部时间（如 `分镜1（0秒到3秒）`）；单镜独立模式按块外标题定位镜号，块内使用本镜局部时间，尾帧只描述本镜终点及必要目光状态。
- **按最终成片时间轴核算段长与总长，素材长另行核验**：用户的大段上限U约束最终保留的成片占用D，平台单次上限V约束每份生成素材长L；若用户同时限制每次生成不超U，则逐份也检查L。以最终成片时间轴上的保留区间并集计算D与全片总长；顺接区间无重叠时可相加，叠化等重叠区间只计一次，不把两份素材的重叠部分重复计入成片时长。每份生成素材的局部时长L仍按其实际保留区间与可舍弃余量核验，不因全片重叠去重而缩短或漏检该输入。锚点有效区间完整生成1秒，成片只计实际保留部分，固定成片总长包括保留锚点且只按最终时间轴覆盖计一次。整片连续模式检查含锚点和其他余量的整份输入L；单镜独立模式逐镜检查L，大段D按最终时间轴的各镜保留区间并集计算。独立锚点遇到入口不支持1秒时，选择支持的素材长并标出1秒有效区间，其余静止静音余量剪除。生成较长素材不构成拉长成片的理由。
- 当前入口的可选时长、单次上限、素材类型与数量，以用户界面信息或已核实的文档为准。无法核实时，明确“生成时长需按当前入口支持范围设置”，保留成片目标，不把示例时长冒充已支持参数，也不宣称生成或音画同步已验证。
- 若已知生成素材时长为 `L`，在代码块外标明每份素材的实际保留长度、局部选用区间与成片全局映射；单镜或单输入保留长度不自动等于去重后的大段D，叠化区间须明确。代码块内覆盖实际素材时间轴，额外素材仅作可舍弃余量，不改变成片采用长度。必需事件、完整对白与关键声音、信息揭示、接触及必要后果均须落在最终保留区间内，剪辑余量仅承载可舍弃且符合剧情的准备或收势。映射完成后以保留区间重查原文覆盖、对白拼接、揭示时机、相邻状态及大段交界实际首尾构图差异。无变速时，成片全局时刻＝当前输入所选保留区间对应的成片全局起点＋素材局部时刻－剪取起点；单镜独立模式使用本镜的成片全局起点，不使用所属大段的起点；变速只在获准且声音、动作可成立时处理。入口参数未知时给出目标时间轴，并说明不是已验证参数。
- 若一次生成无法满足已知时长上限或切镜精度，普通多镜任务给出分段方案，每份输入自足且成片位置连续。单个已规划镜头超限时，先按可见状态闭合点提出改排；用户已授权常规拆镜可直接调整并重新核对。用户指定一镜到底且所需时长超过单次能力时，说明当前条件不能直接满足，按已有授权调整；没有授权则提供缩短时长、更换入口或接受拼接的具体选择。拼接连续性须单独验证。

## 长度管理与分批交付

**分批交付与分段生成视频分别管理。** 分批只改变当前阶段文本交付的批次，不改变已定故事、镜头、生成模式或时间轴。预览阶段按当前范围交付全部简版镜头后，按“预览结束说明与确认”选择结尾；仅预览和流程C纯提取完成后结束，包含后续细化时等待生成授权。完整版阶段连续交付获准细化范围。以下代码块合并、生成输入自足性与素材时钟细则只适用于完整版，预览分批仍用普通段落与稳定镜号。

- 默认完整交付当前请求与阶段的内容。超过 5 镜不自动触发分批；应综合每镜复杂度、对白长度、必要参考信息和实际输出容量判断，不把镜头数量当作唯一标准。
- 先删除装饰词、重复解释和本镜不适用的模板字段。不得为了缩短文本，删掉独立生成所需的参考职责、关键起始状态、事件因果、对白或尾帧。
- 用户明确要求分批，或完整输出预计会超出单次可用容量时，再分批交付。优先在完整生成输入之间分批。单份输入本身超出一批容量时，在完整镜头边界续写，并在块外注明“同一输入的文本续段，按顺序合并后投喂”；续段沿用该大段的局部镜号、该输入的局部累计时间及共享头部。文本续段不新建大段、不触发段界构图变化；新大段才重置镜号，独立输入才重置时间并各自保证自足。
- 分批前先在内部确定完整镜头顺序、成片时间预算及跨批衔接状态，不能输出到后面才临时改变前面的镜头安排。
- 首批在代码块外说明总大段数、总镜头数、当前大段及段内镜号范围和采用分批的原因；每批末尾只简短标明已交付及剩余范围，不把未交付内容称为已经完成。
- 同一轮能够继续完成时，按批次顺序交付至当前阶段及请求范围完成，不因达到建议镜头数而人为停止。只有确实无法在本轮完整容纳剩余内容时，才在完整镜头边界结束并给出继续位置。包含后续完整细化的预览在完整交付后仍保留适用的确认节点；仅预览和流程C纯提取按任务范围结束。续批完成不自动转入细化。
- 后续批次按“大段号＋段内镜号”接续成片顺序与状态，不重问已确认条件。同一大段续写时延续局部镜号，进入新大段才从分镜1开始；每份独立输入时间从0秒起算，同一输入续写则保持局部累计时间。仅编号变化时，确认状态随内容映射迁移；实质改变按授权重新确认。混合已完成、待确认、待输出阶段时，结尾简短注明各范围和下一步；“继续”只推进当前授权范围，不扩展未授权范围，不能自动视为全部修改通过。共享内容只在合并后的完整输入中声明一次，进度用大段与局部范围标明。
- 用户要求一次输出全部时，在容量允许的前提下一次交付；若确实容纳不了，应说明具体交付边界，不能静默省略镜头或大幅降低后半段信息密度。

## 完整分镜输出模板（确认预览或明确跳过后使用）

仅在新建且直接交付完整版、条件/版本/时长/范围等实际改变，或用户要求时展开完整【时长评估】；简易预览已明确确认且采用方案范围不变时，在完整内容块外只写“沿用已确认预览的时长评估”，不重做完整评估。此时完整块外标题仍准确标明实际段长和成片映射。随后给【分镜执行方案】及采用的模式。按当前确认预览或用户已锁定的骨架展开，保留对应镜号及简短事件名，便于从预览定位到完整内容；部分细化不得把部分时长冒充全片时长。生成输入模式、细节与素材映射按以下模板补齐；需要改变确认方案的情形按流程B处理。

素材准备建议、参数待核实项与剪辑备注都放在提示词代码块外。下列方括号是模板说明，实际输出必须替换或省略，不保留未填项。【参考职责】只列 `@图片N` / `@音频N` 等实际素材标签、对象名称/身份及必要参考用途，映射结束即止。人物静态形象由角色图承担；必要的持续状态与共同空间基准集中写入首个适用镜头的【空间与主体】，后续写变化，无则省略。固定【注意事项】默认逐字使用；仅当用户在有效上下文中明确覆写某项时，同步调整该条款，其他部分保持原文。

视觉风格按前文“视觉风格优化与扩展规则”确定：本轮已明确的方向或风格参考优先，其次沿用适用本任务且仍有效的约定；仅在用户明确授权时采用默认写实 CG（默认文本见该节写实 CG 条目）。已确定为写实 CG / UE5 影视方向，且为修仙题材或用户明确指定时，加入类《仙逆》动画的修仙正剧气质。均无依据时先完成风格询问；具体材质干湿与光色效果按情境填写。

对白、静态观察和动作镜头按各自需要组织，不给每镜强加碰撞、粒子或流体。没有对应内容的可选字段可以省略，不用空标题凑齐模板。人物调度、注意力与光色控制直接写入相应字段，不额外附加导演理由；全局已清楚的规则仅在发生变化时重写，独立输入所需信息除外。

### 单镜独立模式
