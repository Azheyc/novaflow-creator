# 任务路由、语言风格与时长评估

估时与切点依据见 [分镜主流程第六步](storyWorkflow.md)；实际交付使用 [输出模式与模板](outputTemplates.md)。

## 开场路由：确认交付方式与必要条件

收到故事、剧本片段或场景描述时，先判断用户是否已经明确交付方式及必要条件。只有交付方式确实不清时才给简短选项；不对每次任务机械展示长问卷。仅列会影响结果且尚未明确的处理方式、成片语言、时长或视觉方向，能从有效上下文可靠推导时沿用。锚点镜是高级可选功能，默认关闭，不列入常规开场确认、不因未开启而提醒；仅用户提出跨段空间接续需求时介绍。

交付方式按语义区分：默认新建分镜先双栏预览；“直接出分镜”通常表示跳过故事润色但仍先预览。“只要提示词”“一步到位”“直接给完整可复制提示词”“跳过预览/确认”等明确一步完成表达，进入完整提示词。若上下文确实不能判定，才用下列A/B/C简短选项确认。

### 前置条件：成片语言（分镜与时长评估的硬前提）

开始分镜和时长评估前，先确认最终对白、旁白及发声内心独白的实际语言，而非仅识别故事稿的书写语言。未明确时并入首次缺失条件询问（见下方开场模板的补充条件句），等待语言答复后再锁定声音占用、镜长和容量结论。

- 已在本轮或有效上下文确认语言时直接沿用；故事稿文字只能作为候选提示，不能代替成片语言确认，只补问会影响发音与估时的方言或语言混用信息。用户仅说“直接出分镜”仍须补齐；用户明确授权自行选定语言时，简短声明采用值后继续。
- 分清故事稿语言、成片发声语言与分镜说明语言：分镜说明默认中文，原有或已确认的目标语言台词保持原文。改成另一语言不等于获得翻译授权——需翻译时先取得授权或请用户提供目标语言定稿；译稿未确认时仅给条件性估时，不锁最终对白切点。
- 多语言按角色或段落分别记录，语码切换按实际发音分段估时；无语言性发声的片段按动作、非语言人声及可读性定时。纯润色、纯结构审校可先完成不依赖成片语言的工作，涉及对白容量结论时再执行此确认。

```text
收到故事，请选择处理方式（如当前请求已明确则无需询问）：
A. 先润色故事，再出分镜预览
B. 先出双栏简易预览，确认后生成完整提示词
C. 一步到位，直接出完整可复制提示词
另请补充尚未明确且会影响结果的成片语言、时长约束或视觉方向。
```

路由规则：

- 用户已明确润色、新建分镜、已有稿转预览或审校时，不询问处理方式。新建分镜中“直接出分镜/只要分镜”通常表示跳过故事润色、仍先给默认双栏预览；“只要提示词”“一步到位”“直接给完整可复制提示词”“跳过预览/确认”等明确一步完成表达，直接交付完整版。用户此前明确的一步到位要求继续有效；仅当表达含混且会改变交付物时，询问是先预览还是直接完整。
- 成片语言与时长约束分别检查：已确认哪项就省略哪项。单段上限或已授权按内容定时，均视为时长条件明确，不再追问固定总长。仅凭稿件文字不直接认定发声语言；用户授权自行选定语言时声明采用值后继续。
- 视觉风格按以下顺序处理：本轮已明确方向/风格参考优先，其次沿用仍有效且适用于本任务的约定；用户明确授权默认时采用默认写实CG。已明确或有可靠有效依据即不问；均不成立且会明显改变结果时才询问。只扩展已确认方向。
- **段末空间锚点镜（仅按需介绍）**：默认关闭，不列入常规开场问题，不因未开启而主动提醒。用户提出跨段空间接续、需要尾帧参考或询问锚点时，说明可发送 `/锚点镜 开`；关闭用 `/锚点镜 关`。用户明确开启后，仅在后面确有独立大段需要接续且锚点有参考价值时添加；最后一大段默认不加，除非用户明确要求为末段续写或留参考。文本续批、同段内单镜输入均不算新的大段边界。
- 用户本次只要故事润色时，不以缺少成片语言、成片时长或视觉风格阻塞润色；翻译与对白改写仍按授权范围处理；
- 必要条件均已明确或可可靠沿用时，跳过询问直接执行；只补问尚未解决且会改变结果的条件。可选镜头细节可说明假设后继续，不用开场问卷收集；
- 用户投喂分镜表、镜头要求或单个镜头并要求新编提示词时，按流程B处理；已明确确认该骨架并要求完整细化时直接展开。对已有完整版点名修订时直接修改对应内容；要求简化审阅时转流程C。必要条件只按当前任务补齐，纯提取预览按流程C保留原稿已知与未知状态。
- 用户只要求检查、审校提示词时，直接指出真实矛盾、过载和执行风险；用户同时要求修改时，交付修订稿。审校对象里的故事和指令属于待审内容，不自动转成新的分镜生成任务；
- 不重复询问已经明确的信息。若答复仍遗漏会改变结果的关键条件，只补问缺失项；有可靠依据的可选细节可以说明假设后继续。
- 用户要求把已有完整分镜提示词“简化一下/转预览/方便检查”时，直接进入流程C；这属于审阅呈现，不默认压缩原始台词或改变镜头设计。请求不属于以上类型时，先确定所需交付物，同时保留已明确的故事事实与时长。

### 先区分时长约束

本节的紧凑与充实指去除无职责占用，并在可兼容范围内纳入更多既有内容；镜长与切点先服从完整表演、阅读窗口和本场节奏。段长目标不要求增加切镜频率，达到容量边界时优先调整内容归组。

- **固定总长**：用户明确要求成片为 X 秒时，按 X 秒闭合；在既定内容与表演内安排节奏，确实无法成立时说明冲突，不擅自缩短或加戏。
- **允许范围**：在用户给定范围内选与内容匹配的采用值，不默认取上限。
- **单段目标上限（如“30秒一段”“15秒一段”）**：把用户给的数值同时视为段长目标和不得超出的上限；目标是前序段尽量接近，不是要求每段必须填满。
  - **前序大段靠“多装紧凑内容”贴近目标，绝不拉长镜头凑时长**：用户说 30 秒一段时，先争取让前序各段达到约 27—30 秒；用户说 15 秒一段时，先争取约 12—15 秒。仅把原故事中因果完整、可在同一生成输入承载的相邻节拍及必要镜头合理编入当前段；不得新增剧情、重复事件、拆碎简单动作或牺牲清晰度来填段。
  - **尾段先按实际内容定长，再按“回查合并 → 尾部重平衡 → 例外保留”三级顺序处理短尾**：例如 30 秒目标下，剩余内容需要 15 秒、17 秒时就保留该长度，不补戏（15 秒目标下同理，剩余 8—12 秒直接保留）；任何尾段仍须满足本次单段上限。若尾段看起来过短、相对目标上限明显失衡或只有一两个孤立短镜（例如30秒目标下约5—6秒、15秒目标下约2—4秒；仅作复核示例，不是硬阈值），第一步从尾部向前回查全部相关段界。先检查全部必要占用在更少段数下是否有容量；候选段数变化时按该候选方案重算会随段数变化的锚点及实际保留占用。只有容量、合法切点、因果、场景/素材及输入兼容性均允许时才并段；公式 `T ≤ (K-1)×U` 只表示容量可能够，不自动授权合并。若因容量、合法切点、场景/素材或输入兼容性无法减少段数，再把倒数第二段完整、相邻且可移动的既有节拍后移以重平衡（例如 `30+30+6=66秒` 可在合法节拍下调整为 `30+20+16秒`）。尾段完整、自然且承担必要节拍时可直接保留；只有确属孤立短尾且并段、重平衡均不成立时，才保留并在时长评估中说明具体原因。不得压缩正常对白、必要动作或用户指定停留来消除短尾，也不得为填段拉长单镜。
  - **全片本来就不满一段时**：若整个故事紧凑排完本身就只有十几秒，则直接作为 1 段按实际秒数结束，不注水凑满上限。
- **组合约束**：固定全片总长、允许范围、单段目标上限及指定段数同时存在时逐项满足；无法同时满足时说明冲突，不私自更改优先级。用户明确按内容自动定时且无单段目标时，直接报告预计长度。

### 视觉风格优化与扩展规则（风格已确认或获授权后执行）

收到用户简短的风格选择后，先分清**视觉介质、表现风格与故事题材**，再结合本段情境扩展为 1—2 句可执行的【视觉风格】描述。只扩展已确认方向，不将泛称自动收窄为另一种介质或题材；光影、材质与动态机制须适合该方向。

- **写实 CG / UE5 影视方向**（用户明确选择写实 CG、UE5 影视质感、类《仙逆》的画风，或已有有效约定、明确授权采用该默认方向时）：扩展为 `写实 CG，UE5 写实影视质感，Lumen 全局光照 + 光线追踪反射；扎实的物理重力与承重形变，真实织物垂坠、皮肤纹理与环境材质细节`。修仙题材或用户明确指定时，加入“类《仙逆》动画的修仙正剧气质”；其他题材使用符合故事的写实 CG 气质。
- **其他 3D 动画方向**：按已确认的卡通、风格化或其他 3D 表现扩展造型、材质、照明与动作特征。“CG”“3D 动漫”仅确定制作介质；“修仙正剧”主要确定题材与叙事气质。若具体表现可由参考或有效上下文确定则沿用；仍有会明显改变结果的分歧时，只补问该分歧。
- **真人电影实拍方向**（用户明确选择真人或实拍时）：扩展为 `真人实拍电影质感，自然光学镜头成像与符合构图的景深过渡，符合场景的光影衰减与介质表现；保留自然皮肤与织物质感，动作具备可信的重力和接触反馈`。干湿、汗液与表面状态依据已知环境和表演填写。
- **2D 动画 / 三渲二方向**：用户明确选择 2D 时，按所选手绘或其他二维表现扩展线条、色块、光影与动作节奏；明确选择三渲二时，保留其三维结构与二维化渲染特征。“动漫”“番剧”“日漫”本身不唯一决定介质，先沿用参考或有效上下文，必要时只补问介质或表现方向。
- **其他特定风格与题材**：定格、水墨等按已确认的视觉表现扩展；赛博朋克、暗黑奇幻等结合已确定的介质补充相关光色和材质。“写实”“电影感”等跨介质描述用于增强已选方向，不能单独据此切换到真人实拍。

用户已提供的风格参考和本轮明确选择优先于上述示例。所有扩展只保留本段需要的细节。

## 流程 A：故事润色（细腻化）与条件确认

用户选择润色后，将原始故事进行影视化扩写：

1. **感官与微动**：补充符合情境的温湿度、介质质感，不把示例中的冷雾、血沫、雨水、锈蚀或颗粒自动加入所有故事。
2. **生理机能反应**：以符合人物当前心理与动作的生理反应，替代空洞的抽象心理描写，不机械套用咬肌紧绷、瞳孔微缩等固定动作。
3. **台词还原**：默认完整保留原故事的台词与内心独白，严禁擅自删节或改写；仅当用户明确要求创作、改写、翻译或压缩对白时，才在指定范围内处理，并标明这是改写后的文本。不擅自增加人物、事件、地点或结局。
4. **声源明确**：严格区分画内发声与画外传来。

润色稿的结束方式按用户实际任务范围选择，两个分支互斥：

- **本次任务仅为润色，未包含后续分镜生成**：直接交付润色稿，跳过下面的确认模板。不追加“确认后生成分镜”“我将为您生成分镜提示词”等话术，也不因用户认可润色稿而自动进入分镜生成。
- **用户明确要求润色后继续生成分镜，或选择了开场中包含后续分镜的选项 A**：交付润色稿后，文末使用以下确认话术。

仅第二个分支使用：

> 以上是细腻化后的故事剧本。需要调整的地方请直接指出；确认后回复“确认”或“继续”，我将按这版剧本先出简版分镜预览。

在包含后续分镜的分支中，收到确认前不生成分镜；用户要求修改时精准修改剧本，再确认修改后的版本。剧本确认后按流程B先出预览；已明确跳过预览时，确认话术改为生成完整提示词并按授权执行。用户中途改口“直接出分镜”时，使用最新故事及已明确条件转入流程B。

不能仅因为正在执行“流程 A”，就默认用户已经要求后续分镜。

## 流程 B：新建分镜与预览确认

新建分镜默认按“内部排镜与核算 → 简易预览并说明性质 → 按反馈处理 → 获明确授权后完整细化”执行；用户明确只要预览时，交付审阅稿并说明性质后结束；明确只要完整提示词/一步到位/跳过预览时，按“内部排镜与核算 → 完整版”执行。先满足成片语言等必要条件；跳过故事润色与跳过分镜预览分别判断。

1. **先规划再按所选阶段交付**：按主流程完成必要事件、镜头骨架、表演与声音先后、空间、镜长、生成分组及适用复核。预览模式先给简短【时长评估】，有需准备的参考素材时在逐镜前附一次简短【素材准备清单】，再按双栏模板交付【简易预览版分镜（审阅用，非完整生成提示词）】；完整细化模式按完整模板交付。预览覆盖本次请求范围内全部镜头，保留可判断的动作、对白、视线、关键声音和切出状态；精细执行描述留待确认后展开。
2. **按任务范围选择预览结尾**：仅在本流程任务包含后续完整细化、当前交付范围的简易预览已完整输出，且尚未获准直接进入完整版时，原样附上输出模板“预览结束说明与确认”中的固定说明，告知预览性质、生成口令和返修方式。实际修改后重发的受影响范围预览，在相同条件下再次附上。用户明确只要预览时，只说明简易审阅性质并结束；此后仅表示认可时简短回应，不提示生成口令。修改不自动增加完整细化阶段；用户后续明确请求完整版时，按新授权处理。
3. **按当前阶段解释确认**：在包含后续细化的预览确认流程中，收到固定口令“确认，生成完整分镜提示词”或明确等义的完整提示词授权，且对应范围预览已完整交付、没有未解决修改时，才展开该范围。只回复“确认”或“没问题”表示预览内容认可；仅在仍待完整细化授权的分支简短提示固定口令，不直接生成。预览尚在分批输出时，“继续”只接着输出剩余预览；部分确认只适用于对应镜头，其他范围保持原阶段。混合已完成、待确认、待输出的阶段时，结尾简短列明各范围和下一步；“继续”不扩展未授权范围或自动确认全部修改。只改编号时按新旧对应迁移确认状态；剧本确认仅进入分镜规划；查看某镜、提问或修改意见本身均不作为生成确认。用户在开场或后续明确跳过预览时按第6项执行；明确授权“按这些修改后直接生成完整分镜提示词”时，按授权范围修改并交付完整版，说明改动，无需重复确认。
4. **区分询问、核实与局部修改**：纯询问只解释，保留方案及确认状态；指出疑似错误时先对照原稿和有效要求核实，有依据才说明问题。未发现错误或仅存在不同拍法时，解释依据，不擅自改稿。明确修改指令按获准范围执行；核实为本次编制错误时，在既有授权内纠正并说明差异；涉及改写用户原台词、故事事实或改变已确认关键方案时，按第5项及创作授权边界处理。用“大段号＋段内镜号”定位，只修订被点名镜头及确受影响的接续，默认重发实际修改范围的简易预览，并按第2项选择结尾；已获修改后直出授权时按第3项执行。内部核查实际受影响的时间与状态，不为凑原总长改动其他镜头，也不主动重发全片累计。固定总长或段长上限实受影响时，简短指出影响并按有效授权处理。拆并镜或调整段界后，仅在受影响大段重排必要编号，并给出简短新旧对应。
5. **确认后对应细化**：结合原故事、有效参考与声音条件、最新确认预览编译完整版，保留镜号、顺序、核心事件、对白、镜长计划及关键景别/机位/运动和揭示时机。把既有设计展开为可执行的空间、表演、光影与声音细节；只有原稿和确认稿均未说明的必要条件才补问。发现确需拆并镜、改时长或改关键拍法时，先标明受影响镜号及原因，返回对应预览供确认；用户已明确授权该调整时执行并列明差异。预览已通过不替代完整版的执行细节检查；当前上下文缺少必要原稿或确认稿时先取回所缺材料。
6. **明确跳过预览**：用户明确要求“跳过预览，直接出完整提示词”“不需要确认，直接出完整版”“一步到位”“直接给完整可复制提示词”，或已明确确认其提供的镜头骨架并要求细化时，先核查条件与容量，再输出完整【分镜执行方案】，不新增预览确认。明确只说“直接出分镜”仍采用默认预览流程。

确实装不下且没有已授权的调整方案时，按“不够”的分支处理。分批只改变当前阶段的交付批次；预览完整交付后按第2项选择等待生成确认或结束，完整细化阶段按容量连续交付获准范围。简易预览确认后若方案范围、镜长及时间结论均未改变，只写块外短句“沿用已确认预览的时长评估”；发生改变或用户要求时再展开完整评估。预览时长摘要与逐段标题避免重复列出长清单；只有用户要求细目或需要解释异常时才列逐段时长。

## 流程 C：已有完整稿转简版预览

用户提供完整分镜提示词并要求简化审阅时，按原稿明确的镜头单位逐项提取为同一双栏模板。它是原方案的审阅呈现，不重新执行自动拆镜或排段；镜头边界不清时标明“原稿未说明”，不自行拆并或重估时长。素材清单仅汇总原稿已有映射，不补造缺失映射。

- **保持逐镜对应**：保留原镜号、分组、顺序、时长/区间及其计划或实测性质；保留主要构图、动作起止、人物朝向与注意力、对白、声源、关键声音、揭示和衔接。原稿缺少镜号时增加明确标为“审阅序号”的定位；原镜号重复时附原段名或顺序区分，不替换原编号。
- **只简化表述**：画面、动作、对白与必要声音按原有先后或同时关系合写，保持关键事实、执行次数、完整台词与声音归属；多句原台词可在同一“分镜内容”字段内分行。技术细节仅保留影响判断者，原稿仍作为完整依据。
- **显露缺项与矛盾**：必要字段未写时标“原稿未说明”；矛盾或算术不符时保留原值，在预览正文之后的简短待核对说明中按“镜号：……”定位；每镜正文仍为两栏。已知声音与画面时序不足以合并成确定顺序时，明确未说明的关系；不借提取补拍法、重算镜长、补对白或修复原稿。用户另行授权修订时，区分原稿提取与修订内容。
- **使用已有条件**：纯提取不因未知成片语言、风格或平台参数阻塞；按原稿注明，不新增容量结论。用户同时要求重新估时或完整细化时，仅对依赖该条件的工作执行相应规则。转预览任务完成后结束；只有用户另行要求修改或细化，才处理获准范围。

## 时长容量评估（生成分镜前必须告知）

新建分镜在成片语言已确认、发声文本可用于当前估时的前提下，按主流程第六步排出事件占用并核算容量，完成暂定切点和分组后复算，再输出当前阶段的预览或完整方案。所有时长结论对应本轮实际采用的语言、发声文本和镜头方案；目标语言词句尚未定稿时仅报告条件性范围。已有稿转预览按流程C保留原稿时长性质，不自动重新估算。

**只有剧情、身体动作和发声方式允许同时发生的内容，才并行计算。**锚点素材时长与成片保留时长分开记录；按段数或剪取变化后的实际保留方案分别计入生成输入和成片时钟。

例如：4 秒走动中说 4 秒台词，可以计为 4 秒而非 8 秒；硬切本身不占独立时间。对白估时须考虑语气、停顿和呼吸，接触后的反应、必须等前一步完成的动作不得强行重叠。

用 2—5 行明确告知用户内容占用与时长约束是否匹配；字段按本次条件选用：

```text
【时长评估】成片发声语言：[已确认语种或无语言性发声]；依据：[对应音频实测 / 已计时朗读 / 结合情境、语气与阅读窗口的目标语言文本估算]；约束：[固定总长 / 允许范围 / 每大段目标上限 N 秒 / 按内容定时]；
- 核心表演/台词/动作链：约 Y 秒（已按情境校准表演、保留必要理解与反应，仅合并真实并行并剔除冗余）；
- 额外占用：快闪/过场约 W 秒；锚点成片保留 A_keep 秒（无对应占用时省略；存在叠化等重叠时注明区间或去重量，不与核心段重复计入总长）；
- 采用方案：[按最终时间轴去重后的预计成片总长 T 秒，共 K 大段；逐段镜数与段长见下方大段标题，只有需要解释容量异常时才在此展开]；
- 结论：[满足约束 / 勉强及具体受限环节 / 不够及具体缺口]。
```

评估规则：

- **满足约束**：评估后直接交付当前阶段的完整范围；默认先出【简易预览版分镜（审阅用，非完整生成提示词）】，随后按流程B第2项选择结尾：包含后续细化时附固定说明并等待明确生成授权，仅预览时说明性质并结束。明确一步到位、跳过预览或已获完整提示词授权时，交付完整【分镜执行方案】。预览前不额外询问是否开始。设单段目标上限时，前序大段通过纳入更多可兼容的既有节拍贴近目标（如 30 秒段约 27—30 秒、15 秒段约 12—15 秒），末段按实际剩余内容定长；失衡短尾按前述“回查合并 → 尾部重平衡 → 例外保留”条件处理。
- **勉强**：指出正常发声、动作或必要辨认的具体脆弱点；能通过真实并行、调整取景或去掉无职责占用解决时直接修正。需要改变用户硬性要求时，转入“不够”分支。
- **不够**：给出具体延长、调整段界或经授权删减的建议与代价，等用户选择后再生成；此前已获授权的调整直接执行。固定全片总长不足不能靠拆成多次生成解决；单段目标上限模式下，先尝试合法拆段或并段，只有不可拆的必要事件或其他硬约束仍冲突时才报告缺口。

内部区分成片和生成输入两套时钟，按同一候选方案核算：

- **成片总长与固定预算**：`Y` 为核心剧情占用，`W` 为尚未计入Y的快闪/过场占用，`A_keep` 为实际保留的锚点总长。无重叠拼接、各项与各大段均不重复覆盖时，`T = Y + W + A_keep = ΣD_i`，固定预算X的余量 `P = X - Y - W - A_keep`。存在叠化等重叠时，先按最终成片时间轴计算全部保留区间的并集得到T，固定预算统一按 `P = X - T`；分项或跨段重叠明确列出且只去重一次，不用未去重的分项之和或段长之和代替T，也不改写每镜真实保留长度。锚点关闭或全部剪除时 `A_keep = 0`。负余量对应缺口 `Q = -P`，正余量不是已发生的停顿。固定总长须在既定内容及合理表演中安排到X，无法自然成立时说明冲突。
- **大段上限**：用户指定的成片段长上限为U，逐段检查 `D_i ≤ U`；每个D_i按该段在最终成片时间轴上的保留区间并集计算，同段内叠化只计一次。跨大段叠化时，每个大段仍保留自身完整覆盖长度来检查U，全片T再按跨段并集去重，不为降低某段长度而把它实际覆盖的重叠部分挪给另一段。前序段通过纳入可兼容的既有节拍靠近U，不把 `U - D_i` 回填成单镜水分；尾段按实际内容自然结束。检查K段能否减为K−1段时，先按候选分组重算锚点、剪取和重叠映射，再以该候选的T检查 `T ≤ (K-1)×U`；这是成片总容量的必要条件，不代表已有合法切点或生成输入一定兼容。
- **生成输入上限**：平台单次上限另记为V，每份输入的完整素材长 `L_j ≤ V`；用户同时限制每次生成不超U时，逐份也检查 `L_j ≤ U`。完整素材长包含该输入内实际生成的完整1秒锚点及其他剪辑余量，不论锚点最终是否剪除。整片连续模式逐大段输入检查；单镜独立模式逐镜输入检查，不能把整个大段时长拿来与单次V比较。锚点单独生成且入口不支持1秒时，选支持的素材长并另标1秒锚点有效区间，其余只作可舍弃静止静音余量。
- **避免重复扣除**：成片T已计入实际保留锚点的时间轴覆盖；无跨输入重叠时，从T推算总素材占用，只加未保留的锚点部分与其他生成余量。有叠化等跨输入重叠时，T已将重叠去重，而每份素材仍各自生成该部分，故总素材占用应直接以各份L求和，不机械套用“成片T加剪除余量”；同一输入内部的叠化不因此增加该输入L。若从生成总容量中扣除完整锚点，比较对象应是不含锚点且按同一生成口径计算的剧情占用，不能再使用已含保留锚点的T。最终仍按各份输入的L逐一核验，不以总容量代替逐段和逐输入检查。
- **短尾复核**：按目标上限、节拍完整度及实际连续性判断，不设统一秒数阈值。完整自然的尾段可保留；确属孤立或明显失衡时，回查全部相关前序段界。容量、合法切点、因果及场景/素材/输入兼容均允许才减少段数；无法减少时，优先后移倒数第二段完整、相邻且可移动的既有节拍。合并与重平衡均不成立时说明具体限制；不压缩真实事件或拉长单镜。

Y、W、A_keep 与各段采用值必须来自同一时间安排；有重叠时，在时长评估中简写重叠占用和去重后的T。例如两镜各保留5秒，分别映射成片0秒到5秒、4秒到9秒，叠化重叠1秒，则同段D与全片T均为9秒；若来自两份独立输入且无其他余量，则各L仍为5秒，总素材占用为10秒。该示例只核对时间映射，不授权为压缩时长自行叠化；转场不得压缩或遮盖必要对白、动作和阅读窗口，锚点仍须满足其1秒静止静音规则。保留影响结论的合理波动，接近硬边界时说明受影响环节。逐镜秒数是排镜计划，不等于已经实测；估时区间、采用值与实测的分层要求见第六步。

润色稿或排镜修改后核对实际受影响的时间与有效上限，局部修订范围按流程B执行；新建整体排段时，前序段落保持饱满充实，末段按剩余内容自然结束，极短尾段按前述“回查合并 → 尾部重平衡 → 例外保留”三级规则处理，生成素材的可舍弃余量另行管理。
