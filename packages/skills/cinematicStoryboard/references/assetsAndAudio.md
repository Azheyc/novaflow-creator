# 参考素材、角色声音与对白

在 [分镜主流程](storyWorkflow.md)确定事实与知情边界后使用；成片语言和风格遵循 [路由规则](routingAndDuration.md)，职责和音色编译至 [输出模板](outputTemplates.md)。涉及素材准备与绑定、角色声音或对白时读取相应部分，按交付阶段展开。

**交付阶段**：本文件的资产映射、【参考职责】、【角色声音】及完整音色等模块在收到固定确认口令或等义完整提示词授权后，或明确跳过预览时，于完整版中展开。预览前可在代码块外给一次简短【素材准备清单】，沿用全任务稳定的 `@图片N` / `@音频N` 编号与已有映射，分别记录本次所需素材的提供与绑定状态；无素材条目时清单可省略，用户明确不用某项参考时省略该项。待上传或未确认对应关系的内容不得称为已绑定；清单不重复逐镜职责、完整音色或外貌设计。预览只在“分镜内容”中合写原台词、必要声源/发声类型与关键声音，使用清楚的角色或物件名称；素材职责、身份和声音连续性仍在内部核对。已有稿转预览按流程C忠实提取：只汇总原稿已有映射，不推导新槽位，缺失状态可说明为未知；原稿未说明的条件保留为未知。

## 参考素材职责与引用规则

每份素材的职责须明确。同一素材可按用户指定承担多项职责；冲突时按用户指定的主参考或基础图处理，不擅自混合互斥设定。区分“待绑定素材槽位”和“已提供真实素材”：故事推导的 `@图片N` / `@音频N` 映射可以先写进提示词供用户上传替换；实际收到素材可记录为“已提供”，只有素材与该编号的对应关系已确认后才可记录为“已绑定”。

- 角色图：作为该角色静态形象、服装、身份与明确可见装备的视觉参考；提示词中不再重复文字描述这些静态外观；
- 场景图：控制建筑、地理、材质、地标和环境主光方向；
- 道具图：控制形状、比例、材质、状态和接触位置；
- 风格图：只控制色彩基调、光影质感与画面氛围，不改变人物结构与物理空间；
- 首帧图：控制生成起始时已存在的构图、人物位置、姿态、道具和环境状态；
- 上一镜或上一大段截图：仅作为截图中可见人物、姿态、道具与空间状态的连续性依据，不自动锁定下一镜的景别、机位或构图；确认截图是否对应最终保留终点，中间帧不冒充末帧，画面不能证明被遮挡事实或音频时序。下一段按段界规则另选画面并接续动作；用户明确指定该图兼作首帧时，核对其与段界差异要求的兼容性；
- 参考视频 / 白模视频：默认提取主体空间站位、走位路径、构图景别、镜头运动轨迹与切点节奏；用户未指定时，不迁入白模视频中的简模几何外观、纯色材质与生硬肢体。人物静态外貌由角色参考图承担；文字只保留用户明确提供、且与本镜故事或连续性直接相关的事实，不另行设计或重复描述人物外观；
- 参考音频：控制指定角色的音色特征（如 `参考 @音频1 的音色，仅参考音色`），不把参考音频的原词句或背景杂音迁入新镜头。

**引用与指代规则（新建分镜时自动结合故事判断并生成 `@图片N` / `@音频N` 待绑定资产映射槽位；流程C已有稿转预览仅汇总原映射，不据此推导新槽位）：**

- **自动推导本段所需资产并建立标准编号映射**：结合故事情节判断本段（或本镜）实际需要的核心角色、关键场景、关键道具及发声角色音色，在【参考职责】的“资产映射”中直接按标准格式填入具体名称与稳定编号：
  - 标准格式：**`@图片1是角色[具体角色名]，@图片2是角色[具体角色名]，@图片3是场景[具体场景名]，@图片4是道具[具体道具名]，@音频1是角色[具体角色名]的参考音色，仅参考音色，@音频2是角色[具体角色名]的参考音色，仅参考音色`**。
  - 其中的“某某”必须结合当前故事或分镜内容具体填写（例如：`@图片1是角色李强，@图片2是角色张三，@图片3是场景青云宗山门广场，@图片4是道具赤霄断剑，@音频1是角色李强的参考音色，仅参考音色，@音频2是角色张三的参考音色，仅参考音色`；此例仅演示格式，严禁将示例名称照抄到无关故事中）。
  - **按本段实际需要列出**：图片槽位对应本段需保持身份的可见角色、实际场景及关键道具；音频槽位对应有对白、旁白或内心独白的声源，包括画外发声者。只有指定非语言人声、且需要保持音色身份的角色同样可列音频槽位；本段不发声的角色省略音频项。没有关键道具就省略道具项，纯画外声源无需为本段额外准备人物图。用户已有素材映射原样沿用，新增槽位使用未占用编号。
- **同一任务编号稳定，映射与素材状态分开**：先为全故事建立资产对应关系，每份输入只列其中实际所需条目，同一资产跨段沿用编号。用户指定的编号与对象优先沿用，其余槽位顺延且不冲突；用户提前指定编号只确认对应关系，不代表素材已提供或已绑定。分别如实记录“待绑定”“已提供”“已绑定”，只有实际确认对应关系后才称已绑定。尚有待绑定槽位时，仅在代码块外提示一次“请上传对应素材并替换或绑定标签”，块内保留具体职责即可。
- **具体名称由故事填写**：使用原故事的角色名、地点名与道具名；没有专名时使用明确身份或描述，如出租车司机、便利店门口、乘客遗落的晾衣绳，不自创姓名或资产来凑条目。示例人物与场景仅演示格式，实际输出全部按当前故事替换。关键道具是承担辨认、持有、交接或状态变化的必要物件，不为所有背景摆设分配槽位；同类素材的数量随故事变化。
- **保持用户的素材选择**：默认预填所需图片与音色映射，不要求用户先上传才能出分镜。用户明确某项不用参考素材时，取消该项槽位；人物外观仅按用户明确给定或授权的内容处理，不自行补充。已提供角色图时不重复描述其静态外貌，用户明确要求保留的文字特征除外。实际入口标签与预设编号不同时，按确认后的对应关系同步替换所有引用，不把两套编号混用。
- **人物与资产形象职责**：角色静态形象以对应参考图为准。【参考职责】只列素材标签、原名或明确身份及必要的参考用途，到映射结束即止，不追加人物外观或重复说明段落。各分镜直接用角色名或标签编写位置、朝向、姿态、动作、目光和情境表演；故事中影响动作、辨认或连续性的状态变化按实际发生记录。
- **分镜正文中的协同指代**：在【空间与主体】【角色声音】及各分镜正文中，对应角色、场景、道具和音色同步使用资产映射里的 `@图片N（角色/场景/道具名）`、角色名、场景名、道具名及 `@音频N` 保持一致，方便用户直接上传素材替换前面的 `@图片几`、`@音频几`。没有参考图的路人/龙套不占用 `@图片N` 槽位；仅按用户提供的姓名、身份或位置指代，不自行补写其静态外貌。

### 人物外观描述边界

- 使用角色图时，以素材映射承担静态形象，预览、持续事实及完整分镜均不再重述人物外观。
- 无角色图时，以原名、身份或必要位置区分人物，不自行设计外观；只有用户明确提供或授权且影响本镜叙事的特征才照实保留。
- 群像和路人沿用既定人数、身份、可见性及必要位置与行动。角色表情和状态随已有剧情发展，自主细化既有表演不等于新增静态形象。

## 对白与声画咬合

- 将已确认的发声语言与必要方言特征写入【角色声音】；混合语种在对应对白处注明。分镜说明保持其约定语言，台词保持用户提供、确认或明确授权生成的目标语言原句；仅用作音色参考的素材不覆盖发声语种。未经翻译授权，不把中文原稿自行改写成外语台词。对已确认或获授权的外语对白，默认每句旁附可删除的“（中文：……）”阅读释义；用户明确要求净版时省略。释义只辅助理解，不改变目标语言原句，不视为更换成片发声语言；中文不发声、不计时、不做 Lip-sync，也不作为字幕。每份独立输入在代码块外统一提醒一次“投喂前删除中文释义”；跨镜分段时就近附释义，但不重复完整原句。已有稿转预览仅提取原文，不擅自新增翻译或释义。

- 默认只使用用户给定的对白、旁白与内心独白，不擅自增删或改写词句；用户明确要求创作、改写、翻译或压缩对白时，按指定范围处理，并标明这是改写后的文本。以角色或声源标识加引号保留最终文本，并标明画内对白、画外对白或内心独白；有同步要求时注明所用时间轴内的发声区间。
- 长对白先找语义转折、听者反应和有意义的行动，再决定留镜还是切镜；没有变化时允许持续观察，不以对白句数或统一的时间阈值决定切换。用户指定一镜到底时，用镜内表演、视线或焦点安排承载变化，不擅自剪开。
- 对白内容跨镜分配时，使用同一声音事件核算完整发声窗口，每镜只计该声音在本镜实际占用的部分。可按语义拆出原文片段，各段合并后与完整文本一致；或在起声处保留完整原句一次，后镜明确续声与结束位置。同一次输入选用一种清楚的写法。画面切给听者时，声音仍属于原说话者，按可见范围更新画内或画外标注。独立输入分别写明实际承担的词句与发声阶段，必要音轨接续在块外交接，文字安排不等于已生成连续音频。
- 画内角色说话时，嘴型和呼吸随原台词及发声强度变化，不统一写成“嘴部微动”。全局【注意事项】与【角色声音】已声明的 Lip-sync 规则和稳定音色不逐镜复述；各分镜“音频与对白”写明发声区间、说话者及有明确对象时的受话者、画内/画外类型、原台词及当镜拟音/环境声变化。对决定估时或较前句发生变化的说法，紧贴本句写明自然连贯、急促回怼、重音落点或必要停顿；发声窗口与该句说法一致，不能只在全段头部笼统写一种语速。
- **画外发声时**：明确声源位置或身份，画内人物不对这段画外台词匹配口型。画内嘴部状态服从实际动作，可以张口喘气、哭泣、进食或微笑，不强制闭唇，也不固定情绪。同一角色的内心独白不要求其画内身体说话。
- 只有对应画内对白的说话者匹配该段台词口型；其他人物可自然反应。画外人物、声源和关联物体是否入画，按本镜明确的可见范围控制，不能因写出声源而自动入画。
- 同一角色的声音身份与同一场景的声场保持连续，情绪改变可以影响语气、气息和音量，不等于随意换声线。仅在动作或情绪确有需要时写笑、叹、抽泣等非语言人声，不默认添加；独立生成的声音一致性不能仅靠文字描述保证。
- **角色声音与音色设计（【角色声音】）**：本段（或单镜）有可见人物或画外人声时，在【注意事项】之后输出【角色声音】模块；无可见人物且无画外人声时省略。画外说话者同样属于发声角色。身份字段用于保持角色一致性，声音设计与发声内容必须同时遵守观众知情边界；身份待揭示时，仅使用此刻已允许听出的音色与表演特征：
  - **有对白或语言性发声的角色（同时保留 `@音频N` 音色参考与完整角色音色描述）**：默认在【参考职责】分配音色槽位，并在【角色声音】中**同时保留 `@音频N` 引用与完整的角色音色描述**，严禁因为加入了 `@音频N` 就删掉原有的音色描述。统一写为：`- [角色名] Voice：参考 @音频N 的音色，仅参考音色；一名[年龄段与身份定位]，[口音/语种特征]；[声部、音色质感与共鸣位置]；[语速、句尾走向与节奏特征]；[常态气质及本段情绪/压力下的声音变化]。`（其中 `N` 与前面资产映射中的该角色编号一致；若用户明确声明某角色不用音频参考，则仅去掉前半句 `参考 @音频N 的音色，仅参考音色；`，完整保留后面的音色描述；角色次要不自动免除音色映射与音色描述）。真实音频已提供且可读取时，在已分配的角色音色职责内以该音频为主，文字描述据实对齐，并服从用户有效上下文指定的主参考；不得把拟设计断言为已听取的音频。尚未提供或无法读取音频时，文字音色仅为暂定设计，每份独立输入在代码块外统一标注一次。绑定后若差异影响角色身份、语种或已确认方案，按用户授权处理；不得擅改已确认方案。去除同一输入内重复的提示，但每份独立输入的音色描述须自足。
  - **无台词但有指定非语言人声的角色**：写明“本段无台词”，仅列出剧情已给定或已授权、且动作情境确有需要的喘息、哭泣或闷哼等及其发生区间；保留所需声音身份，不为这类角色强填口音、句尾等对白字段。没有台词不能直接推导为完全不发声。
  - **完全静音的角色**：仅在剧情或用户明确要求该角色不发声时，写明适用区间及“人声静音，以身体行为呈现”；人物动作产生的物理拟音是否保留另按场景要求处理。嘴部姿态仍服从身体动作，不因人声静音强制闭唇。
  - **无台词且未指定非语言人声的角色**：写明“本段无台词，仅按既定动作反应”，不自动增加人声，也不追加完全静音或闭唇要求。人物之后开口或发声时，按对应时间区间更新，不能将局部静音锁成整段永久状态。
- 音轨默认使用用户给定的台词、旁白和内心独白，以及物理拟音 SFX 与环境自然底噪；非语言人声仅在上述条件成立时加入，并在音频行注明。默认固定【注意事项】原文保留；用户在有效上下文中明确覆写其中某项时，只按该授权同步调整对应条款及音频行，其余条款原文保留。所需非语言人声在具体音频行明确作为人物表演拟音，不因无对白就强加呼吸声。禁止生成任何硬字幕、文字条、水印或 BGM 音乐（除非用户在有效上下文中明确覆写要求）。声音终点、跨镜延续和静音按剧情或用户指定处理。
