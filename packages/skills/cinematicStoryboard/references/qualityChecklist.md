# 交付前质量检查

按 [分镜主流程](storyWorkflow.md)、[画面与调度](cameraAndStaging.md)、[素材与对白](assetsAndAudio.md)、[输出模板](outputTemplates.md)核对；按交付阶段、输出模式、场景复杂度和本次变更取适用项，纯润色或局部审校只执行适用项，不要求预览具备完整字段，也不要求普通场景加载全部高级规则。

## 内部质量检查（交付前核对，不输出）

先核对交付阶段，再按A—F六组执行适用项。新建预览检查方案事实、节奏与连续性，详细执行字段只在完整阶段检查；完整细化检查与确认预览的对应关系及全部执行要求。已有稿转预览以忠实提取为准，缺项和矛盾据实标明，修改须有授权。纯润色和局部修订仅检查相关范围。

**阶段与预览检查**
- 已区分新建预览、预览续批、仅预览、纯询问、局部修改、确认细化、明确跳过、已有稿转预览及审校；包含后续完整细化的流程B预览完整交付后附固定说明，收到固定确认口令或明确等义授权才展开对应范围。仅预览和流程C纯提取只说明审阅性质，交付或认可后结束，不附生成口令；明确跳过或授权修改后直出时按获准范围完整交付。“继续”的含义与当前阶段一致，部分确认仅覆盖相应范围。确认预览且采用方案范围不变时只写“沿用已确认预览的时长评估”；只有新建直接完整版、条件/版本/时长/范围实际改变或用户要求时才展开完整评估，块外标题仍准确标注段长和成片映射，部分细化不冒充全片。
- 预览在简短时长评估之后、逐镜之前只出现一次【素材准备清单】；按全任务稳定编号列实际需要的图片和发声角色音频，标注待绑定/已提供/已绑定真实状态，沿用已有编号，缺少类别或不需要则省略，不增加逐镜第三栏或重复清单。流程C只汇总原映射，不补造，不因未知语言或素材阻塞。
- 仅编号变化时确认状态随内容映射迁移；实质改变按授权重新确认。混合已完成、待确认、待输出范围时，结尾简短说明各范围和下一步；“继续”不扩展未授权范围，不能自动视为全部修改通过。
- 外语对白默认每句原文旁附可删除的“（中文：……）”，只供阅读，不发声、不计时、不匹配嘴型、不作字幕；用户明确要求净版时省略，纯流程C不自动新增翻译或释义。
- 每镜标题能唯一定位，正文只有“镜头基础信息”和“分镜内容”两栏；画面、动作、完整对白及必要声音按真实先后或同时关系合写，避免重复描述问话与回答。原声源、画内/画外、旁白/内心独白及跨镜续声可辨；长对白在同栏内分行，未为简短而遗漏。普通镜头可在同字段合并短句并省略不适用项，同一输入稳定事实/声音只写一次；独立输入仍须自足。头脸朝向、目光、任务、持物及伤势按需要明确，不机械填满所有部位。
- 预览覆盖当前请求的全部摄影镜头及已开启锚点；结尾已按模板“预览结束说明与确认”的适用范围选择。纯询问只解释并保留方案及确认状态；疑似错误先核实，确需修订时遵守流程B授权边界；实际修改后重发受影响范围预览，仅在包含后续细化且未获修改后直出授权时再次等待生成确认。站位基准、关键朝向与目光、道具变化、揭示和切出状态可判断，技术细节按审阅需要保留。镜头时长与生成余量分清；不要求预览具有完整版的完整字段。固定注意事项及完整素材/音色字段在完整阶段落实。锚点默认关闭且不询问、不提醒。
- 收到固定口令或明确等义的完整提示词授权后细化，并与最新确认稿的镜号、顺序、核心事件、原台词、镜长及关键拍法对应；拆并镜、改时长或关键拍法已有明确授权或先回到对应预览确认。只有已同意的细节展开直接进行，已确认骨架不被默默重排。
- 已有稿转预览保留原号、原值和原意，缺项标“原稿未说明”，实际矛盾按镜号提示；未用重新导演、补对白或重新估时替代忠实提取。只要审阅稿时说明性质并结束，不附生成口令；用户仅表示认可时简短回应，另有明确修改或细化请求才继续。
- 局部修改仅覆盖点名镜头及实际受影响接续；时间与编号变化在必要范围内核查并说明，不为维持旧总长重排其他镜头。

**A. 成片语言与对白**
- 成片发声语言已确认，有实际录音时目标语言台词与录音匹配；语言、译稿或读法变化后重算声音占用、反应起点与切点，保持分镜说明语言、台词语言及翻译授权边界。
- 对白时长已按本句说法校准：日常问话自然紧凑，急促回怼承接当前情绪；真实重音、换气与犹豫按需保留。发声区间和语气描述一致，没有把激动一律算作加速，也没有按固定字速慢读或重复铺垫情绪。
- 对白完整标明声源与口型归属，画外音允许符合剧情的非说话嘴部动作；长对白跨镜合并后完整且未重复，跨镜声音仍属正确声源；用户指定的事件、对白与终点完整保留。
- 完整版中的【注意事项】与默认原文或用户明确覆写后的有效条款一致，未覆写部分完整保留；有可见人物或画外人声时【角色声音】按发声角色同时写齐对应 `@音频N` 音色引用（沿用全任务稳定编号）与完整的角色音色描述（年龄身份、口音语种、声部质感与共鸣、语速句尾与情绪变化，未因加入 `@音频N` 而删减音色描述），并区分语言性发声、指定非语言人声、无台词仅动作反应与明确的人声静音；不把无台词当成完全不发声、不把局部静音扩为整段、不强制闭唇；分镜内不复述全局音频与唇形规则。

**B. 原文覆盖与知情时机**
- 原文必要动作、对白、旁白、声音和终点都有镜头承载，行动前后事实与主要落实位置唯一且可信。
- 先识别节拍、观察对象与信息边界再选摄影参数；关键揭示在首帧、镜内和尾帧保持正确时机。
- 书页、屏幕与操作面的有效朝向支持真实观看，观众读到的信息没有被错误转成角色已知；视线、证据插入与反应的组合没有无意泄露知情或改变人物选择。

**C. 镜头选择与表演**
- 每次切镜承担新的理解或有意义的观看变化，连续表演、听者反应与证据选用可读的承载方式；每镜观察目标清楚，删并只影响冗余覆盖，未破坏事件、对白、节奏与时长。
- 行动目标、阻力、策略与后果来自故事，表演符合人物所知、景别、时间与双手任务；特写对象是当前变化的实际承载者，景别裁切保住关键脸、手、对象与同时性，并给局部变化必要阅读时间。
- 直接交流时受话对象、身体朝向、头脸朝向与目光对象分别明确；听者注意力与当前说者及自身任务相符。操作时按辨认、对准、检查或确认回应的需要在人、手与物之间分配目光，具有实际触发；摄影机关注对象与人物目光目标未混淆，画外对象方向及跨镜视线接续明确。
- 阅读窗口从对象真正可读时核算，遮挡、失焦、注意转移和同时听新事实/看操作/读字的负担已检查；人物需要视觉监控的任务与看人按真实先后或成立的并行安排。
- 同框、过肩或干净单人的选择有具体关系依据，过肩前景未遮重点，POV 来自合理视点且符合人物可见与可知范围；大透视有明确近远关系与可见依据，机位、视野、转向与变焦区分清楚，角度未被机械绑定身份。
- 空镜或插入承载既有信息、后果或有意持续体验，未漏掉必须看见的动作与反应，未额外暗示时间变化或新增事实。
- 多人或空间复杂场景区分在场、可见与离场，站位走位按需要写清「当前画幅位置与纵深＋场内相对方位及参照基准」；例如人物b面朝门口，人物a位于b的身体右前方、投影在画面左侧，同时明确身体朝向所依据的基准。复杂空间检查画面投影与人物/地标双参照，不直接删基准；普通场景不强制加载全部高级空间字段。人物转身、机位变化与真实位移分别核对；移动结束时写停点，运动中切出时写当时位置、方向与动作阶段，未为模板强加停步。关键接触与道具交接完整；不额外创作或重复描述人物静态外貌：有参考图时由图片承担，无参考图时不自行设计脸、头发、体型或服装；只保留用户/故事给出的必要外观事实及连续性相关变化。
- 表演细节在当前景别与时长内可读，未把静止误判成无表演或塞入多余动作；摄影机路径受已知空间支持，没有为凑技法安排穿墙、撞障碍或互相冲突的运动。
- 光源、色彩与材质有依据且连续，画面效果未遮掉需读懂的信息，未擅自添加雾、道具或背景人物。

**D. 时长、节奏与分段容量**
- 逐镜秒数来自自然发声、当前动作阶段、角色注意力兼容性和有效阅读窗口；情境快慢与表演依据明确，必要预备、反应及停留完整，无机械加时或减时。
- 指定单段目标时长（如30秒一段、15秒一段）时，前序各大段已通过合理多分配剧情与分镜尽量贴近目标上限（如27—30秒或12—15秒以内），且绝未为了凑够段长而拉长单个分镜的时长。
- 短尾仅触发复核而非阈值：30秒目标下5—6秒、15秒目标下2—4秒仅作示例。检查尾段内容是否孤立、比例是否失衡及容量/合法切点/场景或输入兼容性；完整自然的尾段可直接保留。确属孤立短尾时，先尝试合法减少段数，并重新核算候选方案中的锚点；若受容量、合法切点、场景或输入兼容限制无法减少，再重平衡，仍不成立才说明保留原因。合并前后剧情真实占用不变；不为填满或消短尾而压缩、拖长剧情。
- 估时区间、采用值与实测分清，采用值依据情境而非统一偏向区间某一端；接近硬边界时按合理偏慢表演或估时上沿核查。固定成片总长与余量包括实际保留的锚点，Y、W与A_keep按同一时间轴计量；有重叠时明确区间并在T中去重。减段后按候选重算，已计入成片的锚点未再次扣除。用户段长U逐大段检查D，平台单次V逐输入检查L，单镜独立模式未误将整段D与单次V比较；独立锚点的1秒有效区间与入口支持的素材长分清。
- 切点兼顾必要理解、连续表演和既定情绪；信息刚可辨认、换说话者或人物转眼未被自动当成切镜指令。每场已复核长短关系及连续短镜，缺少观看价值的碎切已合并，合并后剧情真实占用、对白和状态接续一致；锚点/剪取造成的合法变化单独核算，用户指定平均镜长只作全场参照，未设统一最短镜长。
- 主画面片段按最终时间轴覆盖实际采用的成片总长并满足适用约束；同段内叠化的D及全片T按保留区间并集去重，各镜实际保留长度不被改写，跨大段叠化仍逐段核验自身完整覆盖长度。无重叠时才直接相加；固定总长余量统一按X减T，重叠分项不重复计入。跨输入重叠的总素材占用直接按各L相加，不能用去重后的T加剪除余量冒充；同一输入内部叠化不重复增加L。时间区间统一写为 0秒到3秒、3秒到4.5秒等秒数表达，保留必要亚秒精度且无多余尾零；快闪落位、剪取区间与起止状态明确，未将目标精度宣称为生成保证。
- 关键场次最晚结束的事件依赖、人物获知与观众辨认分别核对；合理估时上沿与不同切点安排暴露的真实冲突已处理，局部改动后已沿依赖回算。

**E. 结构与编号**
- 场次、节拍、摄影镜头、镜内阶段、大段、输入与文本批次区分清楚，各镜以“大段号＋段内镜号”唯一覆盖，全局区间、局部时间与剪取映射相符。
- 每大段从分镜1连续编号；单镜独立模式只按输入归零时间而不重置段内镜号；文本续批延续同一大段与输入的编号及时钟。
- 相邻大段最终保留的末画面与首画面在景别或明显视点/构图上不同，移动镜头按实际首尾而非标题比较，差异已在下段开头体现；变化保住轴线、动作阶段、视线、持物、声音与知情边界。锚点默认关闭且不询问、不提醒。用户开启后，仅同一故事连续性确需接续且后面还有下一大段的适用段末追加1秒；最后一大段默认不加，明确要求为末段留参考/续写时可例外。单镜独立模式按大段接续判断，不逐镜加。生成素材含完整1秒，成片仅计实际保留部分；按实际锚点数和保留方案重算占用，不设固定每K段增加K秒。开关变化按授权重算受影响段和编号，不压缩剧情；文本续批末尾或当前批末尾不算全片末段。锚点展示当前机位可见且允许揭示的关键空间关系并保留真实遮挡；素材区间、保留方案及映射明确，剪除后按实际末画面重查段界，无法有效取景时说明限制。
- 首帧静态状态、镜内主体动作与摄影机行为、尾帧结果互相兼容；局部修正后已回查下游边界。
- 所选输出模式符合用户意图；把任意完整生成输入（文本续段先合并）与其他输入隔离后，仍能明确必要参考、风格、场景、主体、初始状态、光源与声音。
- 块外索引与块内分镜标题职责明确：大段号、段内镜号范围及跨段引用放在块外，整片连续模式的块内标题保留本段镜号与输入局部时间；代码块内没有未填模板项、找图建议或后期操作说明，局部风险锁仅在有风险时正向书写。分批确有必要，进度中的大段及镜号范围准确，无后半段漏项或过度压缩。

**F. 素材、风格与事实边界**
- 【参考职责】完整阶段按实际需要写出具体角色、关键场景、关键道具与发声角色参考音色映射；资产编号全任务稳定，已提供与已绑定状态区分，未把待绑定槽位声称为已上传素材。【参考职责】只列实际素材标签、名称/身份及必要参考用途，映射结束即止；持续事实与共同空间基准放在首个适用镜头的【空间与主体】，无额外人物外观或重复说明。有角色图时由图片承担静态形象；无角色图时也不自行创作外貌。白模视频只提取站位、走位、构图、运镜与切点，不迁入简模外观。预览素材清单仅列实际需要项一次，并据实标状态；流程C只忠实汇总原映射，不补造，也不因未知语言或素材阻塞。
- 区分摄影机投影、人物身体朝向与稳定地标参照；左右前后的基准明确，转身后的方位称谓变化未被误判为真实位移，道具、伤势、破损与主光连续；持续事实在【空间与主体】中只收录本次输入内不变的必要状态，可变持物、伤势与破损逐镜更新。
- 视觉风格优先用本轮方向或参考，其次沿用适用的有效约定；仅在明确授权时启用默认、仅在仍无依据时询问；风格扩展区分介质、表现风格与题材，未把泛称强制映射成真人或写实修仙。
- 本次仅润色还是润色后继续分镜判定清楚；仅润色时完全跳过分镜确认模板。
- 焦距/FOV 的口径与机位、景别自洽，未作无条件的压缩、浅景深与锐度承诺。
- 未核实的平台参数与未进行的生成测试，没有被写成已支持或已验证。
